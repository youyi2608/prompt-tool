## 上手三步

1. 双击 **`提示词工具.html`**（建议 Chrome / Edge 打开）
2. 右上角「读档」→「📂 手动读档」→ 选 `存档4_示例初级_20260920.json`
   （想让界面布局也跟示例一样：右上角「设置」→ 最下面「布局代码」→ 粘贴 `示例设置代码.txt` 里的代码 → 导入）
3. 装词库：右上角切到「拼装」→ 右栏（模式二的话在搜索栏那一排右边）点 **「📦 词库包」** → 选 `词库.bmz`
   → 等 1~2 秒即可。**只需要导这一次**，以后刷新、重开都自动在。

## 两种模式

| 模式 | 干什么 |
|---|---|
| **复制** | 一屏按钮，点一下复制；分类可折叠、可加「折叠线」；购物车可批量复制 |
| **拼装** | **模式一**：左（我的按钮）/ 中（我想要 + 组装框）/ 右（词库联想）<br>**模式二**：五大类 → 小分类 → 词条，像网页一样一层层挑词；含「组合选项」与「🎲 随机抽卡」 |

右下角还有一颗 **「API」** 小圆钮：把「数据摘要」交给 AI，或配好自己的 AI 密钥（DeepSeek / 硅基流动 / 智谱 / 阿里云百炼）直接**说人话**让它给出**行动代码**替你改数据（先预览、再执行，可整批撤回；危险动作不给 AI）。

## ComfyUI 互通（可选，但推荐）

1. 把 `ComfyUI-PromptSync` **整个文件夹**复制进 ComfyUI 的 `custom_nodes\`，**重启 ComfyUI**
   - 官方便携版：`…\ComfyUI_windows_portable\ComfyUI\custom_nodes\`
   - 秋叶整合包：`…\ComfyUI-aki-vX\ComfyUI\custom_nodes\`
2. 确认黑窗口里出现这一行：`[提示词工具] ✅ 互通节点已加载（版本 1.2）：/prompt_sync/ping 可用`
3. 工具顶栏**左上角**点亮 🔗 → 之后点按钮不再复制，而是把正 / 负提示词直接写进节点文本框

### ⚠️ 连不上？新版 ComfyUI 会「不让别的网页访问它」

新版 ComfyUI 自带一层跨源保护：**双击 HTML 打开的工具（`file://`）会被它当成"别的网站"，直接回 403**，
症状看起来是「节点没答话」，其实节点是好的。**两步判断**：

1. 浏览器打开 `http://127.0.0.1:8188/prompt_sync/ping`
   - **返回 JSON**（有 `"success": true`）→ 节点是好的 → 走下面的「路 1」
   - **404** → 节点真没加载 → 看黑窗口有没有 `[提示词工具] ✅` 那行，重启 ComfyUI

2. **路 1（推荐，不用改任何设置）**：重启一次 ComfyUI，然后浏览器打开

   ```
   http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html
   ```

   这是节点里附带的「网页版工具」，和 ComfyUI **同一个来源**，🔗 一定能连上。
   （它和桌面那份的数据不互通，想搬数据就用「存档」导出 / 导入。）

   **路 2**：给 ComfyUI 启动参数加 `--enable-cors-header` 后重启（等于放开那层保护，自己电脑上用、用完删掉即可）。

> 完整排查过程（含 F12 报错长什么样）见仓库里的 **`连不上_案例记录.txt`**。

## 常见问题

| 问题 | 答案 |
|---|---|
| 存档存在哪？ | 用桌面快捷方式（启动器）时：`桌面\工作流\提示词数据.json`，自动备份在 `桌面\工作流\数据自动备份\`；直接双击 HTML 时数据在**你浏览器里**，清浏览器数据就没了 —— 想留文件请用「存档」存成 json |
| 换电脑 / 发给别人怎么带数据？ | 「存档」导出 json，在另一边「读档」导入；界面布局用「设置 → 布局代码」那 43 个字符 |
| 词库每次都要重导吗？ | 不用。导入一次后会落盘（启动器 = 写文件；双击 HTML = 存浏览器），刷新、重开都自动在 |
| 点按钮没复制 / 变成同步了？ | 左上角 🔗 开着的时候，点按钮 = 推给 ComfyUI；关掉 🔗 就恢复复制到剪贴板 |
| 会收费吗？ | 不会。工具完全免费；「AI 配置」里用你自己的密钥产生的费用是交给 AI 公司的，作者一分钱不收 |
