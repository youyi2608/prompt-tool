## 这是什么

| 模式 | 干什么 |
|---|---|
| **复制模式** | 一屏按钮，点一下就把提示词复制到剪贴板（可开互通，直接写进 ComfyUI 节点） |
| **拼装模式** | 左区=我的按钮 · 中间=「💭 我想要」+ 组装框 · 右区=词库联想（机翻 / 手译 / 共现联想三档） |
| **互通节点** | 配 `ComfyUI-PromptSync` 节点后，点按钮 = 把正 / 负提示词**直接灌进节点**，不用复制粘贴 |

其它：收藏、次数排序、自动存档、自定义布局（四态功能按钮 + 43 字符布局代码）、整库导入、导出独立插件页 / 分类文本码、明暗主题。

**4.1 测试版新增**：标签即分类（按标签分组）、分类 / 按钮置顶、空白分页双击删除并顺延、选标签的下拉面板（最近用过的排最上）、负提示词「通用身份」改到专区设置。

## 怎么用（3 步）

1. **双击 `提示词工具.html`**（建议 Chrome / Edge 打开）。想要自动存档到文件，就用启动器打开（见下方说明）。
2. **导入示例数据**：右上角「读档」→「📂 手动读档：直接选择 JSON 文件」→ 选 `存档4_示例初级_20260920.json`。
   想让界面布局也跟示例一样：右上角「设置」→ 最下面「布局代码」→ 粘贴 `示例设置代码.txt` 里的那串代码 → 导入。
3. **想用词库**：把 `词库.zip` 解压 → 进拼装模式 → 右区「📁 **整库**」→ 选整个 `词库` 文件夹。
   不用分辨哪个是哪个，它会自动认出大词表 / 机翻表 / 手译表 / 共现表并分流到对应的层。

> 关于自动存档：本包里的 HTML 在浏览器里用「浏览器本地存储」记数据，换浏览器 / 清了缓存就没了。
> 想让它直接读写硬盘上的 JSON（带自动备份），需要一个本地启动器（PowerShell 写的），
> 那份在作者自己的电脑上、路径写死了，**不方便直接分发**，所以没放进这个包。

## ComfyUI 互通节点（可选，但强烈推荐）

把 `ComfyUI-PromptSync` 整个文件夹复制到你的 ComfyUI 的 `custom_nodes\` 下面，重启 ComfyUI，
就能在节点菜单里找到 **「提示词同步（来自提示词工具）」**（分类：文本/提示词工具）。

然后在工具右上角点亮 **🔗**（互通开关）：之后点按钮不再复制，而是把 **正提示词 / 负提示词分别**写进节点里的两个文本框。
节点自带「从工具同步一次」按钮做手动兜底。
