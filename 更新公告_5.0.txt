## 一、AI 直接帮你动手 🎛

### 1. 行动代码｜让 AI 替你建按钮、改分类、加标签 🔌
右下角多了颗「API」小圆钮：把一份「数据摘要」（你的按钮 / 分类 / 标签 / 负提示词 / 分页 + 词库规模，
不含 32 万词条）复制给任意 AI，再把 AI 回你的「行动代码」（一段 JSON 动作清单）贴回来，
先预览它要干什么、再点执行，整批操作可以一次撤回。

- 白名单动作：新建分类 / 新建按钮 / 改按钮 / 加删标签 / 加负提示词 / 指定通用负提示词；
  删分类、删按钮、清空数据这类危险动作故意不给 AI 用。
- 标签只能用摘要里已有的（想顺带建就在那条动作里写 "createTags": true）；有错就整批不执行。
- 摘要太大（约 8 万字符）可以直接导出成文件拖进 AI 对话框；也能一键切成「精简」版。

### 2. 内置 AI 对话｜说人话，它一次把话说完 ✨
API 面板中间就是一个输入框：配好自己的 AI 密钥（DeepSeek / 硅基流动 / 智谱 / 阿里云百炼
四家都内置了接口地址和模型下拉，也能自定义任何 OpenAI 兼容接口），填一句需求
（例如"新建一个医疗题材分类，再往里放个护士服按钮"），它会一口气给出全部行动代码，
自动填进行动代码框并立刻预览 —— 点不点执行仍然由你决定。

- 可调温度（默认 0.7）和最大输出 token（默认 8192）；另有「破甲词」输入框，避免 AI 因敏感词拒答。
- 密钥只存在你这台电脑的浏览器里，不写进数据文件、不上传。
- 💰 用 API 密钥产生的费用是你交给 AI 公司的，作者没有收 AI 公司的钱 —— 往 AI 公司花的任何一分钱都到不了作者手里。

## 二、拼装模式全面升级 🧩

### 1. 拼装「模式二」｜像网页一样一层层挑词 🗂
拆成 五大类 → 小分类 → 词条 三层，点一下词条就进购物车。
搜索支持"空格任一 / + 且 / - 排除"，结果还会告诉你「其他分类里还有 N 条」。

- 组合选项：把一套词存成成套按钮、指派给某个大类，点一下就整套换上、自动跳到下一个大类；
  设了组合选项的按钮在复制模式卡片左上角有一颗小金星。
- 两个购物车互不干扰：复制模式那辆车装按钮、拼装模式那辆车装词条；车条上边缘还能拖着改高度。
- 🎲 随机抽卡：每个小分类一个滚轮，点词条=固定、再点=换；⭐收藏不会被顶掉、🔒固定不参与随机、
  🗑 拉黑不再出现；抽到的词可以单独重抽，也能把不满意的分类拖走改成别的小分类。

### 2. 组装框与折叠线 🧱
- 点一下左栏按钮，整段提示词被一个虚线框圈起来，右上角一颗 ✕ 一次全删；框里的词照样能单独删。
- 分类编辑里可以给某个分类「加一条折叠线」，按住线往上拖就能把上面的分类一个个折进来。
- 每个分类都能单独折叠，折起来高度和展开时一致，分类名与条数照样看得见。

## 三、词库与互通 ⚙️
- 📦 词库包：导一个加密的 词库.bmz 就一步装好 32 万条大词表、机翻表、共现表、标签分类表，
  并自动落盘 —— 下次打开不用再导。（拼装模式二的搜索栏那一排右边也有这颗键了。）
- 🔗 互通不再依赖启动器：直接双击 HTML 也能连 ComfyUI（端口 8188 / 8189 / 8190 / 8000 / 8001 / 8080 自动找）；
  报错会分清"ComfyUI 没开 / 开着但节点没装上 / 被新版 ComfyUI 的跨源保护挡住"三种，并告诉你下一步查什么。
  ⚠️ 新版 ComfyUI 不让"别的网页"访问它：双击 HTML 打开的工具会被回 403 —— 这时用节点自带的
  「网页版工具」（地址 http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html ）打开就行，
  和 ComfyUI 同一个来源，一定连得上；详见《连接排查.txt》第 0·5 步与《连不上_案例记录.txt》。
