30 秒版：到底要连哪几根线

13 颗里，出图那条链上要接线的只有 3 颗（提示词同步 → 优化节点 → 采样器；空Latent → 采样器）， LoRA 池是「把 LoRA 链拖进去、再从池子接出去」，剩下 9 颗都是「摆在画布上当面板用」的，一根线都不用连。

[检查点加载器] ──CLIP──▶ [CLIP 文本编码优化节点] ──正向──▶ [K 采样器].positive
                                        └──负向──▶ [K 采样器].negative
                              ▲
[提示词同步] ──正提示词──────┘（接「提示词同步·正（可不连）」）
             └─负提示词────────▶「提示词同步·负（可不连）」

[空Latent] ──LATENT──▶ [K 采样器].latent

[套图排队] / [计时器] / [游动羽翼工具栏] / [关键词权重]：不用连任何线
只要这三样接上，工具点按钮 → 出图这条链就通了。

十三颗节点，各干什么、怎么连

（12 颗注册在 ComfyUI 的节点表里 + 1 颗纯前端的「黑箱」，它不占节点列表）

节点要连的线说明
提示词同步
（来自提示词工具）		 两个输出「正提示词 / 负提示词」→ 下游文本节点的输入 工具推过来的正负词就落在这里。只接一个也行、都不接也不影响出图（另一个口空着没事）。 没连任何东西时，它也是好的 —— 你可以先在节点上手改。
CLIP 文本编码优化节点
（就是「优化节点」）		 输入 clip（必接，从「加载 CLIP / 检查点加载器」的 CLIP 出来）
两个可选口「提示词同步·正 / 负（可不连）」← 提示词同步的两个输出
输出「正向 / 负向」→ 采样器的 positive / negative		 正负二合一（内置的「CLIP文本编码」一个字没改）。口里来的优先：连了就用口里那份， 没连就用文本框里写的。两个口连不连、只连一个，都正常出图。
空Latent（自填宽高像素） 输出 LATENT → 采样器的 latent 长边 / 短边像素 + 横竖朝向 + 数量；像素自动向下取整到 8 的倍数。节点上画着等比矩形预览。
套图排队
（来自提示词工具）		 不用连线 要和「提示词同步」一起用：工具里点 🎞 推一整套 → 节点上一张张排队出图（能暂停 / 继续 / 停止 / 清除）。
计时器
（休息计时 + 生图效率）		 不用连线 吃 ComfyUI 自己的出图事件（任何工作流都能计时）：黄条读制图时间、灰条读休息时间，到点响一声放水波。 ⚠️ 那颗「✔ 这张有效」默认是雪藏的 —— 要它回来就点「⏱ 计时设置」里那颗「已雪藏（点一下调出来）」。
游动羽翼工具栏 不用连线 画布上的按钮面板：① 一键把本包的节点加到画布 ② 这本说明书 ③ 改模型别名（只改显示、文件名不动） ④ 🌐 打开同源的网页版提示词工具 ⑤ 小字橡皮擦（把不想看的灰字擦掉，只影响那一颗节点）。
关键词权重
（附属节点）		 不用连线、也不会被执行 从优化节点的「⚖ 调整正 / 负关键词权重」叫出来的一条横长条：拖小圆钮或直接填数字。 它只改「送去编码的那一份文本」，你框里的字一个都不动。
LoRA 池 把画布上的 LoraLoader 拖进池子上框（= 吃掉它）
池子的 MODEL / CLIP 输出 → 下游（采样器的 model、文本编码的 clip）		 一池子装下所有 LoRA：点一下就「暂时失效」、再点一下恢复，亮着的才叠。 能分「角色 / 画风」（角色默认最多 1 颗、画风不限，两个上限都能在 ⚙ 里改）； 还能存组合存档、每次出图随机抽一套。熄灭的 LoRA 不参与，缺文件的也会跳过、不会报错。
自定义优化窗
（节点）		 不用连线（它把要求发给提示词工具，AI 跑在工具那边） 在画布上单独一块：写一句要求 → 点优化 → 工具里配的 AI 改好后写回这段文本。 工具没开就用不了（AI 配置只在工具里）。
图像画廊
（展示 + 存档）		 输入 IMAGE ← 采样器出来、解码后的那张图 出图自动存进「图片存档」，按一次生成 = 一组排放；三页签（主页 / 收藏 / 回收站）、 多选批量收藏删除、点开单张放大。右键一张图还有「🔮 安全复现」—— 把那张图的参数搬回画布。
暂存节点
（下一批文本）		 不用连线（纯前端）；接上「自定义优化窗」的 优化结果（可不连） 之后， 优化结果就先落它的下框 一边出图一边攒下一批稿子：上下两框、各自分正 / 负两层，中间能拖比例； 「↑ 顶掉上框」换上去、「→ 送进优化节点」直接写回 CLIP 节点。「⏻ 关机」= 旁路，不收起来。
模型池
（多套模型并行）		 把加载器节点 拖进面板（按输出类型自动归位）
池子的 MODEL / CLIP / VAE 输出 → 下游		 一竖列三框（紫 MODEL / 黄 CLIP / 红 VAE），几条记录 = 几套模型并排，各自参数独立。 每条名字默认取第一个拖进来的节点名，双击能改；⚙ 里能改别名、把节点吐回画布、勾「带 LoRA 池」。
黑箱 不用连线（纯前端节点，不进 ComfyUI 的节点表） 工具栏第 1 格放一颗到画布，能占满屏幕当大面板：选 LoRA、写正负词、选比例张数， 点「🎨 生成」就在它内部搭一条真工作流出图；「🧨 拆掉黑箱」= 得到一套原版工作流。

三种常见接法

① 最省事（推荐给新工作流）

  1. 画布上放「游动羽翼工具栏」→ 在下拉里挑「提示词同步（来自提示词工具）」→「➕ 加到画布」；
  2. 同样把「CLIP 文本编码优化节点」「空Latent（自填宽高像素）」加出来；
  3. 按上面那张图连线：CLIP→优化节点、优化节点→K采样器、空Latent→K采样器、提示词同步→优化节点两个口。

② 不想换内置的 CLIP 文本编码

也能用，但要多做一步：右键内置「CLIP文本编码」的 text 框 → Convert Widget to Input（转成输入口），再把「提示词同步」的输出接上去。

⚠️ 接了线就是「覆盖」关系、不是相加：那个框里就算还留着老文本，也不会被算进去（它根本不进 API 图）。 想图个眼净，把框里的老文本清空即可；忘了清也不影响。

③ 完全不动工作流

在「提示词同步」节点里直接复制文本，手动粘到内置 CLIP 文本编码里 —— 节点不连线也能这么用。

排错：连线相关的三个常见毛病

  • 出图跟工具的提示词对不上：先看「提示词同步」节点里是不是空的 —— 它只在工具推过来的那一刻有内容， 工作流里存的老文本会在打开 ComfyUI 时被清掉（这是故意的）。
  • 优化节点不工作 / 报错：八成是 clip 没接（它是必接的），或者接的不是 CLIP 类型。
  • 连点几个按钮出的图只剩最后一个词：那是「连接模式」的限制 —— 点单个按钮只送这一个词； 要一次全送好几个，先在工具里进购物车、再点「复制全部」。
