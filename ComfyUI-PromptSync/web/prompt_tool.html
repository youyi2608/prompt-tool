📖 教程

    

      

        
Q：为什么什么都看不到？

        
A：说明还没有导入数据。点击「读档」导入数据之后就能看到一些信息了。当然也可以选择不导入数据，直接从零开始，一个一个新建按钮。

      

      

        
Q：我想新建我自己的按钮？

        
A：点击右上角「新建」键。如果觉得点击新建之后展开的「高级选项」内容太过复杂，也可以先不展开，直接填上名称和提示词先新建，之后再拖动调整或点击编辑修改。

      

      

        
Q：怎么调整顺序？

        
A：长按可以拖动按钮或分类：按钮可以拖到其他分类，也可以拖到左中右其他区域；分类同样可以上下调整顺序、跨区拖动。
双击分类箭头（▶ / ▼）可一键展开 / 收起所有分类。

      

      

        
Q：主界面右边那几个页面是什么东西？

        
A：那些是分页。在主界面中打开「123 显示」，可以设置一个按钮所在的分页；一个按钮可以同时在多个分页中。分页自己也可以双击重命名；某一页空了以后，双击它就能删掉（会先问你要删还是要改名；删掉后后面的分页往前顺延、分页名称不变，1 2 3 4 删第 2 页 → 顺延成 1 2 3）。分页最多 6 页、最少 3 页。

      

      

        
Q：标签功能是什么？

        
A：购物车中会排斥掉相同标签的按钮（选择了某个标签的按钮后，其他同名标签的按钮会自动隐藏）；同时点击标签，也可以一键搜索出所有同名标签的按钮。

      

      

        
Q：负提示词是什么？

        
A：负提示词与正提示词绑定对应。新建负提示词时可以选择它对应的正提示词；复制正提示词时会弹出提示，可顺手复制对应的负提示词；购物车批量复制时也会一并提示所有对应的负提示词。

      

      

        
Q：显示图像是什么？

        
A：图像模式共 4 种，点一下循环切换：① 不显示图像（鼠标浮上去也不会弹图）；② 只显示已有图像（缩略图，鼠标停一会儿能看大图）；③ 只显示已有图像（详细图，直接铺开大图）；④ 显示所有图像（没图的按钮显示「点此导入」的虚线框，点那块才导入）。图片会自动压缩保存；点按钮永远是复制，想换图就点图片右上角的「换图」，或者右键按钮再按 Ctrl+V 粘剪贴板里的图。

      

      

        
Q：存档和读档是什么？

        
A：共 5 个存档位、5 个读档位，可保存和恢复全部数据。还支持双击「存档 / 读档」快速保存 / 读取，当然需要先在「设置」里指定双击对应的档位。

      

      

        
Q：自定义布局？

        
A：功能按钮可以任意自定义布局：在「设置」中，每个功能按钮都可选右上角（图标 + 文字）或右下角（小圆钮），还可以拖动调整排列顺序。

      

      

        
Q：随机模式是什么？

        
A：点击右下角「随机」小圆钮，会随机抽取几个已有按钮弹出，点一下即可复制；可以「再抽一次」，也可以限定抽取范围（左中右区域可多选）。

      

      

        
Q：购物车模式是什么？

        
A：进入购物车模式后，点击按钮不再复制，而是加入底部购物车栏；在购物车里可以一键「复制全部」，多个文本按空一行分隔拼接（开启「紧凑复制」后改用逗号连接、不换行）；点按钮旁的 ✕ 可随时清除。

      

      

        
Q：黑夜模式是什么？

        
A：一键切换黑夜 / 白天模式，夜间使用更护眼。

      

      

        
Q：染色是什么？

        
A：编辑按钮的高级选项里可以选一种轻淡底色作为标记（蓝、绿、红、黄等），方便区分用途；选「默认」可恢复无颜色。

      

      

        
Q：互斥是什么？

        
A：互斥按钮在购物车中不能同时选择（双向生效）。在编辑按钮的高级选项里点击「＋ 添加互斥」，再在灰紫滤镜模式下点选目标按钮，即可建立互斥关系。

      

      

        
Q：功能按钮的布局会随存档保存吗？

        
A：不会。功能按钮的位置（右上角 / 右下角）与顺序存在当前浏览器本地，不随「存档 / 读档」保存。换浏览器、换电脑或发给别人后会恢复默认布局，需要在「设置」中重新调整。

      

      

        
Q：拼装模式是干什么的？

        
A：左上角「复制 ｜ 拼装」切过去就是。左边是你的按钮、右边是词库联想、中间是「我想要」+ 组装框：点一下左栏按钮或右栏词语，它就变成一个小模块；模块可以拖着排序、点 × 删掉，模块上的中文单击能改、双击认可机翻。把模块往上拖到「我想要」还会把它当成一个词块去搜相关词。拼好之后「📋 复制」或「🔗 送到 ComfyUI」。既适合从零拼一句话，也适合把现成的提示词拆开改。

      

      

        
Q：链接节点是什么？怎么装？

        
A：它就是让工具和 ComfyUI 直接对话的那座桥（工具左上角那个 🔗）。装法：把工具附带的 ComfyUI-PromptSync 文件夹整个复制进 <你的 ComfyUI>\custom_nodes\，重启 ComfyUI。之后点亮 🔗，点按钮就不再复制，而是把提示词直接写进 ComfyUI 节点里的文本框（正向、反向两条线分开走，互不干扰；绑定了负提示词的正提示词会一起送过去）。ComfyUI 没开或没装节点时会自动退回复制，不会「点了没反应」。

      

      

        
Q：装了节点却连不上 / 找不到节点怎么办？

        
A：三种情况最常见。
① 找不到「提示词同步」这个节点：先确认装进了正在运行的那个 ComfyUI 的 custom_nodes\ 里——秋叶整合包是 …\ComfyUI-aki-vX\ComfyUI\custom_nodes\（整合包里常有好几层 ComfyUI 目录，别放错），装完必须重启 ComfyUI，然后看它启动时的黑窗口有没有报错。
② 🔗 点开没反应、节点里文本不变：工具支持直接双击 HTML 用，这时它会自己去找 ComfyUI 的端口（8188 / 8189 / 8190 / 8000 / 8001 / 8080 挨个试）；如果你把 ComfyUI 改到别的端口，就用启动器打开并加参数 -ComfyPort 你的端口。
③ 想让 🔗 亮起来更省事：用启动器打开就有「自动转发」；直接双击 HTML 时工具是直连 ComfyUI（节点的接口已经放行本机来源，不用额外设置）。

      

      

        
Q：次数排序是什么？

        
A：它按你复制过多少次把按钮从多到少重排，最常用的自然浮到最前面。点一下是「全局平铺」，再点一下变成「分类内排序」，第三下关掉、恢复原样。某个按钮的次数想在「编辑 → 高级选项」里清零也可以。

      

      

        
Q：收藏怎么用？

        
A：按钮上的小 ♥ 点一下就能收藏 / 取消（嫌碍眼可以在「设置」里关掉 ♥ 的显示）。点右上角「收藏」进入收藏页，里面只列你标过 ♥ 的按钮，常用的放一屏就够。收藏是跟着按钮名字记的，改名会一起走。

      

      

        
Q：自动存档是什么？存在哪？

        
A：它是防手滑的兜底：数据一有改动就自动留一份，间隔在「设置」里选（1 / 2 / 5 / 10 / 15 / 30 分钟，默认 5 分钟），也可以整个关掉。用启动器打开时，按钮数据在 桌面\工作流\提示词数据.json，自动备份在 桌面\工作流\数据自动备份\（按天留，最多 30 天）。想找回旧的就点「读档」→ 用左下角那一档自动存档。

      

      

        
Q：功能按钮的四种状态是什么？

        
A：在「设置 → 功能按钮设置」里，每个按钮都能选四种状态：右上角（图标+文字）、右下角（小圆钮）、折叠（收进一排，点右上角的「«」展开／收起）、隐藏。按住 ⠿ 还能拖动调顺序。这套设置只记在当前浏览器里、不随存档走；想整套发给别人或换电脑，用「设置 → 布局代码」导出那 43 个字符。

      

      

        
Q：拼装「模式二」怎么用？

        
A：拼装模式左上角有「模式一 ｜ 模式二」两个页签。模式二是像网页一样一层层挑词：上面一排是五大类（角色 / 穿搭 / 画面全局 / 头部神态 / 形体），点进去是小分类，再下面是词条——点一下词条就进底部购物车（再点拿出来）。搜索框支持 空格=任一、+=必须同时含、-=排除；搜索还会告诉你「其他分类里还有 N 条」，点开就能看。攒够了一键复制或送进 ComfyUI。

      

      

        
Q：组合选项是什么？

        
A：把一整套词变成一个"套装"。做法：在购物车里攒好词 → 底部「💾 存为成套」→ 再去那个按钮的「编辑 → 高级选项 → 组合选项」里把它指派给一个大类。之后在模式二那个大类的「组合选项」区点一下，就用这一套换掉这个大类已经选的词，并自动跳到下一个大类；指了组合选项的按钮，在复制模式的卡片左上角会有一颗小金星。

      

      

        
Q：🎲 随机抽卡怎么用？

        
A：拼装模式二右下角那颗骰子。每个小分类都有自己的滚轮：滚轮里点词条=固定它（🔒 之后不再参与随机），再把某个钉住 ⭐收藏（收藏不会被挤掉），或者把不喜欢的词条拖到右下角 🗑 拉黑（以后不会再抽到）。抽出来的词在「当前组合」里排队：点词条本身=重抽这一个，点 ✕=这一类不参与，拖动=调顺序；底部可以「🎲 大分类随机」或「🎯 全部随机」。抽卡是按热门度加权的，热门词更容易出现。

      

      

        
Q：分类上的「折叠线」是什么？

        
A：分类编辑弹窗里勾一下「➖ 在这分类之上加一条折叠线」，这个分类上方就会出现一条线；按住线往上拖，经过的分类就被一个个折进来（拖到哪折到哪），点一下线=全部展开、线上的 ✕=取消这条线。一个分区（左/中/右）同时只生效最靠下的那一条。

      

      

        
Q：右下角那颗「API」是干什么的？

        
A：让 AI 帮你操作这个工具。① 数据摘要：把你现在的按钮 / 分类 / 标签 / 负提示词 / 分页打包成一份只读快照，复制或导出成文件给任意 AI；② AI 配置：填自己的密钥（DeepSeek / 硅基流动 / 智谱 / 阿里云百炼四家内置了地址和模型下拉，也能自定义），配好之后直接在这里说人话，它会一口气给出全部「行动代码」，自动填进下面的框并预览；③ 行动代码要先点「👀 预览」看它要干什么、再点「⚡ 执行」，执行完整批可以一次撤回。删分类 / 删按钮 / 清空数据这些危险动作故意不给 AI 用。密钥只存在你这台电脑的浏览器里。

      

      

        
Q：组装框里的虚线框是什么？

        
A：点左栏的按钮时，它的整段提示词会被切成几个小模块、并用一个虚线框圈起来：框右上角那颗 ✕ 一次就能把这一段全删掉，框里的词照样能单独 × 删、整段能按住拖动排序。自己手打或从右栏点进来的单个词不会成框。

      

      

        
Q：什么是「标签即分类」？

        
A：在「设置 → 界面显示」里可以打开。打开后主界面改成按标签分组，一个按钮会同时出现在它的每个标签组里（没有标签的落到「保底分类组」）。它只改显示方式，分类数据一个字节都不动，关掉就恢复原样；每个分组右上角的 ✎ 可以改分组（标签）名、也能一键给组内按钮都加上这个标签。

      

      

        
Q：搜索栏左边那颗「Anima / SDXL / NovelAI」是什么？

        
A：输出格式开关（复制模式和解锁后的拼装模式二各一颗，同一个开关，默认 Anima）。它只在你「复制出去 / 推给 ComfyUI」的那一刻把提示词换成对应写法：Anima = 空格分隔、权重 (tag:1.2)、画师词前面带 @；NovelAI = {tag} 加强 / [tag] 减弱（一对约 5%）；SDXL = 原样输出。按钮里存的还是原样（导出为按钮、存为成套、存档、分享码都不转换），所以来回切格式不会越转越歪。设置 →「词条与格式」里还有一颗「转换时补该格式的推荐前缀」（默认关，只有 Anima 有官方模板）。

      

      

        
Q：双击词条改的不是中文名吗？

        
A：默认还是改中文名。设置 →「词条与格式」里有一颗开关「双击词条改「英文名」」：打开之后，随机抽卡里的词条、模式二列表的词条、模式一右栏的词条，双击改的就是真正进提示词的那串英文（输入框清空 = 用回原来的英文；词的身份不变，购物车和词表命中都不受影响）。

      

      

        
Q：🔗 打不开、说连不上 ComfyUI 怎么办？

        
A：先看提示是哪一种：①「没找到在跑的 ComfyUI」= ComfyUI 没开或端口不对；②「ComfyUI 在跑、但互通节点没答话」= 节点没装好，或者浏览器 / 新版 ComfyUI 把请求挡住了 —— 用浏览器打开 http://127.0.0.1:你的端口/prompt_sync/ping，能回一小段 JSON 就说明节点是好的。
如果你是秋叶整合包：不用去改 ComfyUI 里 run_NVIDIA 那个 bat 文件，只要在整合包的「高级选项 → 自定义参数」里加上 --enable-cors-header，再重启 ComfyUI 就行（这条修法来自粉丝 罗生 Rawson 的反馈 🌟）。连不上时工具会自己弹出这个提示，弹过就勾「以后不再弹」。
另一条不用动 ComfyUI 的路：用它自带的同源「网页版工具」打开 —— http://127.0.0.1:你的端口/extensions/ComfyUI-PromptSync/prompt_tool.html。

      

      

        
Q：右下角那颗「套图」是干什么的？

        
A：把一整套提示词编好、一次推给 ComfyUI，让它一张一张出。点右下角「套图」进面板 → 几个方框各放一组正 / 负提示词（把页面里的按钮拖进框，或拖到顶上那两条虚线 = 所有框都加；也可以点虚线进选择模式、连着点几个按钮；负提示词那一栏也能直接拖进来）→ 每张之间休息 N 秒（默认 60，低于 60 只给琥珀色提醒、不拦你）→ 点「🔗 推给节点」，再去 ComfyUI 的「套图排队」节点上点「▶ 开始排队」。休息是在 ComfyUI 队列外面等的，所以随时能停、随时能暂停 —— 节点上那颗「⏸ 暂停排队」只在这一张出完之后才停（不会把正在出的图掐断），同一颗键会变成「▶ 继续排队」。

      

      

        
Q：负提示词的顺序能调吗？

        
A：能。在负提示词那一栏按住某一条 0.5 秒，它变淡、边框成虚线 = 已经开始拖了；移到别的那一条上，虚线框停的那一格就是松手后它去的位置，松手才真的换。拖着的时候不会被选中文字了，也不会一抖就散。另外负提示词也能直接拖进「套图生成」的方框（套图面板开着的时候，长按是"拖进框"，排序会主动让位）。

      

      

        
Q：ComfyUI 那边多了哪两个节点？

        
A：① 「游动羽翼工具栏」：一个下拉列出我们自己的节点 + 「➕ 加到画布」，不用去搜索框里翻名字；还有「✎ 模型别名」（给 Checkpoint / LoRA / VAE 那些下拉换成你认得出来的名字，只改显示，文件名一个都不动）和「🌐 打开提示词工具」（从 ComfyUI 里打开同源网页版，最稳的连接方式）。② 「套图排队」：配合上面的套图生成，一张一张排队出图，能暂停 / 继续 / 停止；它顶上写着「需要和「提示词同步」节点一起使用」，「提示词同步」节点顶上则写着「需要把 CLIP 文本编码节点的文本置空」。这两个节点都不参与工作流（不接任何线也能摆在画布上当按钮面板）。

      

      

        
Q：打包版第一次打开问我"要不要导入示例存档"，是什么？

        
A：这一版的打包版第一次打开会直接问一句 —— 按「确定」就把随包附带的示例存档装进来（一套现成的按钮 + 负提示词，可以当样例看、也能直接改）；按「取消」就从空白开始，以后不再问。不用担心顶掉自己的数据：导入永远不覆盖，重名会自动加 -1。（只有「打包版」有这个弹窗，你自己电脑上那份本体不会问。）

      

      

        
Q：网页版工具怎么打开？和双击 HTML 那份有什么区别？

        
A：三条路：① ComfyUI 里「游动羽翼工具栏」节点上的「🌐 打开提示词工具」；② 浏览器直接开 http://127.0.0.1:你的端口/extensions/ComfyUI-PromptSync/prompt_tool.html；③ 双击发布包 / 分享包里那份 HTML。前两条是同源页面，连通最稳；第 ③ 条是 file://，新版 ComfyUI 默认会拦跨源请求（工具会提示你给 ComfyUI 加参数 --enable-cors-header，分享包里的 bat 已经加好了）。⚠️ 同源页面和 file:// 那份各有各的浏览器存档（localStorage 不互通），别以为数据丢了 —— 想看数据就固定在一条路上用。
