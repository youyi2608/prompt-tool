# 提示词工具 · ComfyUI 节点包（2.0）

ComfyUI 自定义节点：把桌面上的「提示词工具」和 ComfyUI 接起来。

这个包里一共 **7 个节点**（全中文、都不需要额外依赖）：

| 节点 | 分类 | 干什么 |
|---|---|---|
| 提示词同步（来自提示词工具） | `文本/提示词工具` | 工具推来的正/负提示词落在这里（本文件主要讲它） |
| CLIP 文本编码优化节点 | `条件/提示词工具` | 正负二合一：两个真文本框 + **粘贴进来的每一段自动套一个虚线框**；框可以 ✕ 删 / − 暂时隐藏 / ⇄ 换掉 / `*` 收成小胶囊；还能单独调**关键词权重**（见「二·十」） |
| 关键词权重（附属节点） | `条件/提示词工具` | 优化节点上「⚖ 调整**正**关键词权重」（在中间）/「⚖ 调整**负**关键词权重」（在下边）叫出来的**横长条**：一个词 + 一颗能拖的小圆钮 + 一个能手动输数值的框（0.05 一格）。不连线、不参与工作流 |
| 空Latent（自填宽高像素） | `latent/提示词工具` | 自己填长边/短边像素 + 横竖朝向（见「二·六」） |
| 游动羽翼工具栏 | `提示词工具` | 不工作的按钮面板：一键加本包节点 + 改模型别名（见「二·七」） |
| 套图排队（来自提示词工具） | `文本/提示词工具` | 一次排一整套提示词、中间自己休息，能暂停 / 继续 / 停止 / 清除；还能存 LoRA 方案（见「二·八」） |
| **计时器（休息计时 + 生图效率）** | `文本/提示词工具` | **画布上的大钟**：黄条读制图时间 / 灰条读休息时间（各自设阈值、各自到点叫一声）；点表盘停表、右下角静音 + 关机；一颗大绿键「✔ 这张有效」；音量可调 + 5 种内置音（含哈基米 / WOW 两个音频文件）。**不参与工作流**（见「二·九」） |

在工具左上角打开 🔗 互通开关后，**点按钮就不再复制到剪贴板，而是直接把提示词写进本节点的文本框**；
如果那个按钮绑定了负提示词，正负会一起送过来，分别写进「正提示词」「负提示词」两个框。

> **连不上？先看这一条（2026-09-24 加的）**：新版 ComfyUI 自带一层**跨源保护**
> （`server.py` 的 `origin_only_middleware`：只要请求头里 `Sec-Fetch-Site: cross-site` 就直接回 **403**）。
> 双击 HTML（`file://`）打开的页面，浏览器一定把它算成 cross-site → 于是**直连必然被 403 挡住**，
> 报错看起来像"节点没答话"，其实节点是好的。
> 两条路：① **推荐**——用本节点自带的「网页版工具」打开（见下面第五节）；
> ② 或者给 ComfyUI 启动参数加 `--enable-cors-header`（会放开那层保护，自己的机器上用完可以撤掉）。

## 一、安装

1. 把整个 `ComfyUI-PromptSync` 文件夹拷到**你正在用的那个 ComfyUI** 的 `custom_nodes\` 里：

   | 你用的是 | 该放进哪个目录 |
   |---|---|
   | 官方桌面版 / 便携版 | `…\ComfyUI\custom_nodes\ComfyUI-PromptSync` |
   | **秋叶整合包** | `…\ComfyUI-aki-vX\ComfyUI\custom_nodes\ComfyUI-PromptSync` |
   | 自己装的 | `<你的 ComfyUI 根目录>\custom_nodes\ComfyUI-PromptSync` |

   ⚠️ 整合包里常常有好几层 `ComfyUI` 目录（启动器一层、本体一层），**要放进真正在跑的那个**——
   放错了就会出现「找不到节点」。

2. **重启 ComfyUI**（必须）。重启时留意启动的黑窗口，如果本节点加载失败，那里会有报错。
   **怎么算装好了**：黑窗口的启动日志里应该出现这一行（1.2 起会打印）——
   `[提示词工具] ✅ 互通节点已加载（版本 2.0）：/prompt_sync/ping 可用`
   有这行 = 节点真的加载了；**没有这行**、或者出现 `[提示词工具] ⚠ …` = 没挂上，把那段报错发我。
   另一步：浏览器打开 `http://127.0.0.1:<端口>/prompt_sync/ping`，返回一小段 JSON 就是活着。
3. 浏览器按 **Ctrl+F5** 强刷（自定义节点的 JS 会被缓存）。

没有任何第三方 Python 依赖，不需要 pip install。

## 二、使用

1. 打开「提示词工具」（桌面快捷方式，**或者直接双击那个 HTML 都行**）
2. 点左上角的 **🔗** 打开互通开关
   - 提示「已连通 ComfyUI（127.0.0.1:8188）」= 一切就绪
   - 提示「ComfyUI 在运行，但还没装上互通节点」= 节点没装好或没重启
   - 提示「没找到在跑的 ComfyUI（试过端口 8188 / 8189 / …）」= 端口不对或 ComfyUI 没开，此时点按钮会自动退回复制到剪贴板
3. 在 ComfyUI 里添加节点「**提示词同步（来自提示词工具）**」
4. 回工具里点任意按钮 → 节点的两个文本框当场更新

工具会**自己找 ComfyUI 的端口**（8188 / 8189 / 8190 / 8000 / 8001 / 8080 挨个试）；
如果你的 ComfyUI 在这 6 个之外的端口（比如 9000），目前**自动探测到不了**——用启动器打开并加参数
`-ComfyPort 你的端口`，或者把 ComfyUI 换到上面任一个端口。

**输出怎么接**（两种都行）：

- **直接连线**：节点有两个输出「正提示词」「负提示词」，接给下游的文本节点即可（下游若是 CLIPTextEncode，需要把它的 text 控件右键「Convert Widget to Input」转成输入口才能接线）

⚠️ 节点顶上有一行灰字提示：**需要把 CLIP 文本编码节点的文本置空** —— 那个框里要是还留着老文本，
就和这里送过去的分不清到底用了哪个（不确定的话点开对应节点按一下清空）。
- **手动粘贴**：不改工作流，直接把节点里的文本复制过去

**手动兜底**：节点上有一个「从工具同步一次」按钮，用于自动推送没生效时手动拉取最后一次内容。

## 二·五、网页版工具（连不上时用这个，2026-09-24 加）

本节点附带一份**和桌面工具一模一样的网页版**，放在节点的 `web/prompt_tool.html`。
⚠️ **前端 js 和这个网页版放在同一个 `web/` 目录里**（2026-09-26 修）：ComfyUI 里一个节点模块**只会被挂载成一个 web 目录**（`nodes.py` 里 `EXTENSION_WEB_DIRS[module_name] = …`），以前 js 在 `./js`、网页版在 `./web`，挂载名只有一个 → `prompt_tool.html` 会 **404**（粉丝反馈的就是这个）。所以现在 `__init__.py` 里写的是 `WEB_DIRECTORY = "./web"`，两个文件一起挂出来。

ComfyUI 会把每个节点的 web 目录挂到 `/extensions/<节点文件夹名>/`，所以装好本节点并重启后，直接访问：

```
http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html
```

（端口按你实际的 ComfyUI 端口改；`ComfyUI-PromptSync` 要和你放进 `custom_nodes` 的文件夹名一致。）

**为什么推荐这条**：这个页面和 ComfyUI **同一个来源**，浏览器不会再把它当成"别的网站"，
ComfyUI 那层跨源保护（`Sec-Fetch-Site: cross-site → 403`）就不会触发，🔗 一定能连上。
注意：网页版的数据存在**它自己那个网址下**的浏览器里（和桌面那份不互通），
想用同一份数据的话，用「存档」导出一份、在另一边读进来即可。

## 二·六、附带的「空Latent（自填宽高像素）」节点（1.3 起）

同一个节点包里的第二个节点，跟提示词无关，纯粹是省事：**不用再记长宽像素、也不用猜尺寸下拉。**

| 排 | 控件 | 意思 |
|---|---|---|
| 1 | **长边像素** | 长边那条的像素数（默认 1152） |
| 2 | **短边像素** | 短边那条的像素数（默认 896） |
| 3 | **横边为长边还是短边** | 左右那条边用长边还是短边像素数（默认 长边） |
| 4 | **竖边为长边还是短边** | 上下那条边用长边还是短边像素数（默认 短边） |
| 5 | **数量** | 一次生成几张 |

这样"现在是横图还是竖图"是**你自己指定**的，不用去猜别的预设节点下拉里那个尺寸（它们的毛病就是分不清横竖、还全是英文）。
像素数不是 8 的倍数时向下取整（latent 只能是 1/8）；两条边都选同一条（比如都选「长边」）就老老实实出 **1152×1152 正方形**，不会替你改。两条默认值出来就是横图 1152×896。

节点在分类 **`latent/提示词工具`** 下，名字「**空Latent（自填宽高像素）**」，输出一个 LATENT，直接接采样器即可。

## 二·七、附带的「游动羽翼工具栏」节点 + 模型别名（1.4 起）

分类 **`提示词工具`** 下的第三个节点。**它不参与工作流**：没有输入输出、也不是输出节点，
ComfyUI 永远不会执行它、也不占排队 —— 就是画布上的一块按钮面板。

**五组功能（从上到下）**：① 一键把本包的节点加到画布；② **📖 节点连线说明书**（2026-10-07 第一百一十四批加的 ——
打开同源页 `web/nodes_guide.html`：13 颗节点（12 颗注册 + 纯前端黑箱）各连哪儿 / 三种常见接法 / 排错，浏览器新标签里能跟画布并排看）；
③ 改模型别名；④ 小字橡皮擦；⑤ 🌐 打开同源网页版工具（**④⑤ 是第一百一十五批互换的** —— 原来打开工具在前）。
**第 6 组「只看选中的节点」已雪藏**（代码没删）。

**功能一 · 一键把本包自己的节点叫出来**：面板上有个下拉列出本包的节点（提示词同步 / 空Latent …），
选好点「➕ 加到画布」，节点就落在画布正中间（省得在搜索框里翻）。

**功能二 · 模型别名**：LoRA / Checkpoint / VAE / UNet / CLIP / ControlNet 这些下拉里的文件名，
可以给它们记一个你认得出的别名：

- 画布上显示**别名**（带灰底），下拉列表里显示的也是别名，**鼠标停在上面才显示真名**；
- **文件一个都不改**，下拉里选中的、工作流和 API 图里存的、ComfyUI 真正加载的，全都是**真文件名** ——
  所以分享工作流 / 换台机器都不会因为"我改过名"而对不上；
- 别名只存在本机节点文件夹里的 `model_aliases.json`（纯 JSON，可以直接手改、也可以拷给别人）：
  `{ "loras/bantan-step00007000.safetensors": "悠悠画风" }`，键 = `种类/下拉里的相对路径`。
- **别名会跟着工作流走，但本地优先**（2026-10-07 第一百一十四批）：你存工作流时，**画布里正在用的那几个模型**的别名会被写进
  `extra.pc_aliases`；别人打开这份工作流、而他本机没给这些模型起过名字时，**就会显示你起的那个名字**（他也能看懂这张图了）。
  ⚠️ 本机 `model_aliases.json` 里有的**永远压过工作流里的**；导出只带"画布上正在用的那几条"，不会把整张表塞进工作流。

**怎么改别名**（刻意**不做**"把上千个文件列成一个下拉"那种界面）：

1. 点面板上的「✎ 模型别名」→ 面板里「画布上的模型栏位」那一段列出你**当前工作流里真正在用的**那几个，点行尾的 ✎ 直接改；
2. 或者点「✎ 点一下画布改名」→ 画布上所有模型下拉会亮起黄框 → **点你要改的那个** → 填别名 → 保存（Esc 退出）；
3. 面板最下面「已经改过别名的」只列你改过的那些，可以再改、可以删（删 = 恢复真名）。

⚠️ 「点选改名」用的是 ComfyUI 前端自己的机制（`options.getOptionLabel` / 控件实例的 `background_color` /
`onClick`），**核对的版本是 comfyui_frontend 1.45.21**。如果哪天 ComfyUI 大改前端结构、别名突然不显示了，
去 F12 Console 看有没有 `[游动羽翼工具栏]` 开头的提示；改别名那个管理面板是稳的那一半（它只读写 JSON）。

**功能三 · 打开同源网页版工具（面板上第 5 组）**：面板上那颗「🌐 打开提示词工具（同源网页版，推荐）」直接在同源页面里打开工具
（地址带 `?from=toolbar`，所以从这儿打开的工具**默认就把互通连上**）。

**功能四 · 小字橡皮擦（2026-10-07 加，面板上第 4 组）**：面板上多了一组 **「4. 擦掉小字（橡皮擦）」** ——
**按住那行 🧽 往任意节点的一行灰字上一拖、松手**，那一行小字就没了（拖的时候光标底下跟着橡皮擦、
压在哪一行哪一行亮红框）。规矩：

- **只擦你在的那一颗节点**：擦除记录写进**被擦那颗节点自己**的工作流属性，所以别的节点、
  **以后重新叫出来的新节点**、别的工作流都不受影响；连那一行占的 20px 高度也一起收掉（不留空行）。
- **误擦了**：在**那颗节点上右键 →「↩ 恢复小字（N 行）」**就回来。
- 面板上紧跟着一行小字说明这个范围。
- ⚠️ **按下钩子挂在控件自己身上（`widget.mouse`），不是 `node.onMouseDown`**（2026-10-07 第一百一十五批修的漏）：
  真前端 `_processPrimaryButton` 是 `let d = getWidgetOnPos(...); if (d) { processWidgetClick(...) } else { … node.onMouseDown … }`
  —— **落点在"控件行"上时 node.onMouseDown 根本不会被调用**，所以那颗 🧽 必须让**它自己**接按下
  （`processWidgetClick` 里 `toConcreteWidget` 对 `pcText` 返空 → 会走 `else if (widget.mouse)`）。
  后来要再挂"按住就拖"的控件，照这个来；测试里的假前端也必须照抄这个**分支顺序**。

## 二·八、附带的「套图排队（来自提示词工具）」节点（1.4 起）

分类 **`文本/提示词工具`** 下的一颗节点（本包第 5 颗），跟「提示词同步」**完全独立**（两种不同用法，各管各的）：
那个是"推一次出一次"，这个是**一次排一整套、中间自己等**。它自己也**不参与工作流、不会被执行**。

**三排控件**：

| 排 | 控件 | 意思 |
|---|---|---|
| 1 | **每张之间休息(秒)** | 每张图之间歇多久，默认 **60**（0~600）。官方建议别低于 60 秒 |
| 2 | **一次最多几张** | 这一轮最多排几张，默认 **4**（工具最多能送 24 段，这里再兜一层） |
| 3 | **每张换随机种子** | 开着的话每张都把工作流里的 `seed` / `noise_seed` 换一个随机值 |

⚠️ 节点顶上有一行灰字提示：**需要和「提示词同步」节点一起使用** —— 这一套提示词是**那个节点**送出去的，
少了它这套排了也不会出图。（同理，「提示词同步」节点顶上写着：**需要把 CLIP 文本编码节点的文本置空**；
2026-10-07 起还多一行 **覆盖关系、不是相加** —— 接了线就只用那个节点里的文本，想改成"相加"做不到，
因为内置「CLIP文本编码」接了口就只用口里那份。**小字嫌多可以擦**：见「二·七」的小字橡皮擦。）

**怎么用**：先在「提示词工具」里点 **🎞 套图** 把这一套（最多 24 段，每段可带备注）推给节点 →
在 ComfyUI 里点节点上的 **「▶ 开始排队」**（节点前端会把**当前工作流**的 API 图一起发过去）→
后端一张一张排；想暂停就点 **「⏸ 暂停排队」**（同一颗键会变成 **「▶ 继续排队」**）；
想停就点 **「⏹ 停止」**（= 不再排下一张 + 收掉还没开始的 + 打断正在跑的那张）；
想**清掉这一轮重来**就点 **「🗑 清除进程」**（= 收掉这一轮 + 清空工具推过来的那几段，回到"等工具再推一次"——
**暂停中或还没开始的时候才让清**，正在出图时它会告诉你先按暂停/停止）。
节点身上会写着：`已收到 4 段 · 本轮 1/2 张 · 已出 1 张` / `正在休息 18 秒（这段时间 ComfyUI 是空的）…` /
`已暂停 —— 点「▶ 继续排队」接着排（已经出的图都在）`。

**暂停的规矩**：正在出的那一张**不打断**，等它出完才停在那儿（节点上会先写
「已按下暂停 —— 等这一张出完就停在这儿…」）；休息里按暂停就是立刻挂住，恢复后把剩下的几秒走完再排下一张。

**内部怎么做的**（排错时有用）：休息**在 ComfyUI 队列外面**，靠节点后端一个喂饭线程：

```
排第 1 张 → 等它出完（轮询这个 prompt_id 的 history）→ 睡 N 秒（分片睡、随时可停 / 可暂停）→ 再排下一张
```

- 换的是工作流里 **「提示词同步」节点的 `positive` / `negative`**，其余节点一个字节不改；
- 顺手把那个节点的标题改成你的备注（`套图 i/n`），这样 ComfyUI 的队列面板里一眼看得出排到哪张；
- 因为休息时队列是空的，**这时候点「⏹ 停止」是立刻停的**；正在出图时点会打断当前那张。
- 暂停落在"两张之间"（这张刚出完 / 正在休息）—— 这也是为什么不会出现"图出到一半被掐掉"。

**节点上还有两样**（2026-10-05 加的，都在前端、不占 `widgets_values`）：
**「✔ 这张有效」**（点一下记一张，计数存在节点属性里）+ **「⚙ LoRA 方案（高级选项）」** ——
把**当前画面里的所有 LoRA**（文件名 + 模型强度 / CLIP 强度）存成方案（**最多 4 个、存了不能改**，
要改就删掉重存），然后**每一张图各自点一个方案**；排到那张时后端按节点 id 把这几个 LoRA 的设置写回它的图
（那颗节点不见了 / 已经不是 LoRA 了 / 强度是连线来的，一律跳过，绝不硬塞）。

⚠️ **计时与提醒不在这个节点上**（他 2026-10-05 明确「计时是单独的节点，不应该是套图排队上的节点」）——
见下面「二·九」。

## 二·九、附带的「计时器（休息计时 + 生图效率）」节点（2026-10-05 起）

分类 **`文本/提示词工具`** 下的第五颗（本包第 6 颗节点），**画布上的秒表 / 闹钟**，同样**不参与工作流、不会被 ComfyUI 执行**
（没有输出、不是 OUTPUT_NODE），所以放几颗都不占排队。

**一排控件**：

| 排 | 控件 | 意思 |
|---|---|---|
| 1 | **制图超过多少秒提醒** | 黄条（这一张已经出了多久）到点响一声，默认 **60**（0~3600，**0 = 不叫**） |
| 2 | **休息超过多少秒提醒** | 灰条（上一张出完之后歇了多久）到点响一声，默认 **0**（0~3600，**0 = 不叫**） |

**节点上看得到**：
- **大表盘（像时钟，占节点主体）**：中间大字写"**上一张出图完成之后过了多久**"
  （正在出图时写这张已经跑了多久），下面一行小字写"上一张用时 / 有效几张"；超过 1 分钟会在盘上写「**+N 分钟**」。
  ⚠️ 节点默认给到 **320×380** 那种大小；把它拖大，表盘跟着长大（半径 34~140）。
- **表盘是简约的**（2026-10-06 第一百零八批他定的：「钟表应该简约，加刻度不好看」）：**没有刻度**，
  只有底盘 + 两圈底圈 + 两条进度弧；而且**表盘固定在「✔ 这张有效」键的正上方**、控件整排被压到表盘下面。
- **两条读秒弧**（2026-10-06 第一百零七批他定的）：**外圈黄条 = 制图时间**（这一张已经出了多久）、
  **内圈灰条 = 休息时间**（上一张出完之后歇了多久）—— **两条各自一个秒数、各自到点叫一声**，互不影响。
- **点一下表盘本体 = 停表且不叫**（盘里写「已停」），**下一次出图自己恢复**；再点一下也能手动继续。
- **右下角两颗小圆键**：**静音**（只关声音、水波照放；盘里键变红写着「静音」）与
  **关机**（停表 + 不再叫，盘里写「已关机」；再点一下开回来）。
- **一颗绿底大键「✔ 这张有效」**：点一下记一张（比原生按钮大一圈、显眼，绿底不是灰的）。
  ⚠️ **2026-10-07 起默认「雪藏」**（他要求"这个按钮雪藏，在计时设置中可以重新调出来"）：节点上默认看不到它，
  去 **「⏱ 计时设置」→ 有效图 那一行的「🚫 已雪藏（点一下调出来）」** 点一下就放回来；再点又雪藏。
  开关存 `properties.pcTimer.showValid`（跟着工作流走，**默认关**）；**记数不丢、代码一个字没删**。
  ⚠️ 它的高度是**钉死的 52px**（2026-10-06 第一百零九批）：DOM 控件在 ComfyUI 前端**没有上限高度**时，排控件那一步
  会把"控件摞下面剩下的空间"全分给它 → 键被拉长、**压住底部那行状态字**（他截图报的「绿色按钮把小字挡住了」）。
  同批还加了 `ensureFit()`：节点尺寸至少装得下「标题栏 + 表盘 + 控件摞 + 状态字」，**老工作流里存的太矮的节点载入时会自己长高**。
- **「⏱ 计时设置…」**：秒数（**黄条 / 灰条两条**，0 = 那一侧不叫）/ **音效** / **音量** / **静音 / 关机** /
  试听 / 导入音效文件 / 恢复默认 / 有效图清零。

**提醒（到点会做的事）**：**响一声 + 放一圈明显的水波**（从表盘中心一圈圈荡开，1.5 秒自己收）。
⚠️ **每一段只叫一次**（他第一百零七批报过"连续叫好多下" —— 以前是"每超过 N 秒就叫一次"，会一直重复）：
黄条到点一声、灰条到点一声，最多两声；要再听就等下一张 / 下一段。
- **音效有 5 种内置的**（2026-10-06 第一百零八批他点的单：「去掉"哈基米（猫叫）""木鱼咚"，加上这两个音效」）：
  「小黄鸭（默认）」「**哈基米**」「**WOW**」「铃铛叮咚」「水滴」—— 其中**哈基米 / WOW 是随包带的两个音频文件**
  （`web/sounds/hajimi.wav`、`web/sounds/wow.wav`，他给的就是这两个附件），其余是现场合成的（不涉及版权、不需要联网）；
  在「⏱ 计时设置…」里点一下就换，还会放给你听。
- **音量能调**（面板里一条滑条，0% = 不响、只放水波），对内置音和你自己导入的文件都生效；不想听就点**静音**。
- 想用自己的音效就点 **📁 导入音效文件** —— 文件会存到节点自己的 `web/sounds/` 里（**不写进工作流**，
  工作流不会因此变大），前端直接当音频播放；想换回来点「↩ 恢复默认（小黄鸭）」。
- ⚠️ **只在"确实有事在跑"的时候才叫**（正在出图，或者套图正在排）—— 全空闲之后就不响了，
  免得你走了之后它半夜一直叫。

**计时靠谁**：ComfyUI 自己的出图事件（`execution_start` / `execution_success`），所以**任何工作流**出图都能计时，
不只套图；顺带会读一下套图排队的 `/prompt_sync/batch/status`，正在排套图时把"休息还剩几秒"一起显示出来。

## 二·十、附带的「CLIP 文本编码优化节点」+「关键词权重（附属节点）」（2026-10-06 起）

**CLIP 文本编码优化节点**（类名 `PromptToolClipSegments`，分类 `条件/提示词工具`）就是内置「CLIP文本编码」
的替身，但文本放在**两个真文本框**里（上正下负），而且：
- **粘贴进来的每一段会自动套一个虚线框**（手打的字不套框）；框上有五颗小键：
  `✕` 删掉这一段、`−` 暂时隐藏（内容留着、不进图、字变淡一半）、`*` 收成一个小胶囊（**照样进图**，点胶囊上的 `↩` 展开回来）、
  `📋` 复制这一段、`⇄` 用剪贴板里的内容替换这一段；文本框右下角还有一对 `⇐` `⇒`（撤销 / 重做，**每个框各管各的**）。
- **小胶囊那一排**（排在文本框上面）：**点名字就地改名**、**点 `↩` 展开回文本框**、
  **最左边那颗 `−` / `＋` = 这一段不参与生图 / 让它回来**（2026-10-06 第一百零九批他要求「胶囊情况下也要有小减号虚化键」）。
  ⚠️ **改过的名字记得住**（同批他报的 bug：「让虚线框变成胶囊又变回来，命名会直接重置」）：名字**按那一段的原文**记
  （存进工作流属性 `chipNames`），展开回文本框再收回来**还是你起的那个名字**（原文改过 / 名字被别的胶囊占了才退回编号）。
- **两个文本框永远一样长、一样宽**：拖其中一个的宽 / 高，两个一起变，节点也跟着变。
- 左边两个可选口（`提示词同步·正` / `提示词同步·负`）可以直接接「提示词同步」节点的两个输出；**连了就以口里为准**。
  ⚠️ **只连一个、或者两个都不连都能正常出图**（2026-10-07）：这两口声明成 `optional + forceInput`，**永远都画着**（空心圈），
  不接也不消失、不影响执行（后端取不到口里的文本就退回文本框）—— 那句提醒挂在**「提示词同步」节点**顶上（第一百一十二批他要求搬过去的）。
- ⚠️ 它和「提示词同步」节点**一个展开、另一个就收起**；**收起 = 里面的文本不参与作图**（这是正常的）。
- ⚠️ **两个口连不连都行**（2026-10-07）：它们是 `optional + forceInput`，**永远都画着**（空心圈），不接也不影响执行；
  这行小字原本写在这个节点上，第一百一十二批按他要求**搬到了「提示词同步」节点**（他原话：「优化节点不要搞这个」）。

**关键词权重（2026-10-06 第一百零五批加的，第 7 颗节点；批 C3；第一百零六批改成正负两张表）**：
优化节点上有**两颗**按钮 —— **「⚖ 调整正关键词权重」挂在两个文本框中间**、**「⚖ 调整负关键词权重」在底下那排键里**（他原话：
「权重从一个『调整关键词权重』改成『调整正关键词权重』『调整负关键词权重』，而且一个放在中间一个放在下边，
这样就可以单独调整拉出正关键词和负关键词的权重了」）：
1. 点开就是**那一侧专属**的权重表（跟着工作流存；正表只管正提示词、负表只管负提示词，互不串门）。没有关键词时它会说
   「**当前没有正/负关键词，需要你自己填**」——写一个词、点「➕ 新建关键词」就记下了，**下次打开还在**。
2. 表里每一个词都对应一条**横长条**（点「调出附属节点」叫出来）：上面写着这个词和权重示数，
   **拖中间那颗小圆钮**左右改权重（**最小刻度 0.05**、范围 `0.05 ~ 2.00`、默认 1），
   也可以直接在右边的**数值框里手动输入**；标题上写着是**正**还是**负**（蓝色=正、红色=负）。
3. 这条横长条**不和任何节点连接、也不会被执行**（没有输入输出、不占排队），也**不会改动你框里的字** ——
   它改的是**送去编码的那一份**：
   - 表里的词在（这一侧的）文本框里出现 → 编码时变成 `(词:权重)`；原文里已经写成 `(词)` / `(词:1.2)` / `[词]` 的，以这张表为准；
   - 表里有、文本框里**没有**的词 → **加到这一侧的末尾**（正表加进正提示词、负表加进负提示词）；
   - 权重写 `1` = 不加括号（等于没改）；匹配忽略大小写、按整词边界、长词优先（`long hair` 不会被 `hair` 抢走）。
4. 表里的词删掉时，它那条横长条会一起收掉（在横长条上**改不了词**，要换词就在面板里删掉再新建）。

## 二·十一、附带的「LoRA 池」节点（2026-10-19 起）

1. **它是真节点**：输入 `MODEL` / `CLIP`，输出 `MODEL` / `CLIP` —— 按池子里的顺序，把**点亮的**那几颗 LoRA 依次叠上去；熄灭的直接跳过（连文件都不查，缺文件也只是跳过、不报错）。
2. **怎么装进去**：把画布上的 `LoraLoader` **拖进面板**就吃掉了；面板行内**点一下 = 暂时不参与**（变淡、排到后面去），要**彻底拿出来**得用「管理」那颗键（拖回去也是回画布，不是删除）。
3. **三个滑块各管一件事**：面板中间那个 = 切换「模型强度 / CLIP 强度」；每行下面的滑块 = 这颗 LoRA 的强度（`0 ~ 2`、最小刻度 0.05，可在 ⚙ 里放开上限）；右边那条 = 列表滚动。
4. **角色 / 画风**：给每颗标一个类别（角色红 / 画风蓝 / 没标紫），可以设「角色最多同时点亮 N 颗、画风最多 N 颗」，超了就自动从后面往前关。
5. **组合存档**：只存点亮的，按「红·角色」「蓝·画风+未标」**拆两份存**，读档只动自己那一区（红档不碰画风、蓝档不碰角色）。
6. 池子底栏那颗勾选「📥 从原图读 LoRA」是**勾选键、不是点击键**：开着之后生图时后端会自动读「画廊第三层选中那张图」的 LoRA 并合并进池子（同名覆盖强度、新的追加）。
7. 尺寸可以按 1/2/3 倍调宽、调高（基准 475×450），多套并排时不会互相压扁。

## 二·十二、附带的「自定义优化窗（节点）」节点（2026-10-19 起）

1. 它是一颗**界面节点**：画布上长得和工具端那个「✎ 自定义优化提示词」窗一模一样（写要求的框 / 一排快捷词 / 写过要求的历史），但**本身不参与工作流、不出图时永远不执行**。
2. 点「开始优化」= 把要求发给**提示词工具**（工具侧轮询 `/prompt_sync/ai/pending` 接手），结果由工具写回被优化的那颗「CLIP 文本编码优化节点」的正 / 负提示词框。**所以提示词工具必须开着**，节点自己不会调 AI。
3. 输出口 `优化结果（可不连）` 长在**本节点**身上：接上「暂存节点」的话，优化结果先落进暂存节点的下框（等你确认），**不接就照旧直接覆盖那颗 CLIP 节点的文本**——CLIP 节点永远是"正 / 负"两个口，不会变成三个。
4. 底栏 `⌨ 快捷键`：**双击**这颗键再按你想用的键就能换（单键也行）。窗开着就一直有效，拖节点、点画布都照样能按；只有"画布上什么都没选中"时，这个键还给 ComfyUI 自己用（不然会抢走 Ctrl+Enter 排队）。
5. 快捷词和历史走 `/prompt_sync/store` 那块共享黑板 —— 和工具里看到的是**同一份**。

## 二·十三、附带的「图像画廊」节点（2026-08 起，2026-10 定型）

1. **代替 `PreviewImage`**：接上 `IMAGE`（可选接 `MASK`），出一张存一张，节点面板里就是画廊本身 —— 文件在磁盘上，**ComfyUI 关了重开也不会丢**。
2. **三层浏览**：主页网格（一格 = 一次生成的一组图）→ 组内并排 → 单张放大（`‹ ›` 只在本组里翻）；主页 / 收藏 / 回收站分三页。
3. **删除进回收站、能捞回来**；**收藏 = 搬进收藏夹**，不占主页那 500 张的名额、也不会被顶掉。
4. 每格左下角有个小三角：**蓝 = 文生图 / 橙 = 局部重绘**，一眼分得出这张是怎么来的。
5. 右键菜单：请神复现（把种子 / 步数 / CFG / 采样器 / 正负词 / LoRA 搬回画布，可撤回）、复制图片（直接粘进聊天框）、加到编辑栏、局部重绘等。
6. 输出 `选中的图（可不连）` / `选中的蒙版（可不连）`：不接输入时读"第三层选中的那张"，`MASK` 优先读 sidecar 蒙版、没有才回退 alpha。
7. 想换存档目录、改上限、改「占满全屏」的快捷键，都在这颗节点的「⚙ 设置」里。

## 二·十四、附带的「暂存节点（下一批文本）」节点（2026-11-03 起）

1. **干什么的**：一边出图、一边把下一批的稿子先攒着 —— 上下两个框（上 = 现在用的、下 = 刚优化出来的），每个框再分正 / 负两层，中间那条分隔线**可以拖**（默认负词只占一行）。
2. 接上「自定义优化窗」的输出口之后，点开始优化的结果**先落下框**；满意了点「↑ 顶掉上框」换上去，或者点「→ 送进优化节点」直接写回那颗 CLIP 节点。
3. 上下框都有**上一步 / 下一步**（翻历史），正负要不要一起翻由那颗开关决定。
4. **「⏻ 关机 / 开机」= Ctrl+B 旁路（bypass）**，不是折叠 —— 关掉后节点变暗、不收起来，在原处点「开机」就能回来；开关机不影响里面存的字。
5. 「new」小标签：这段文字还没用于生图时会亮（改过字、刚从下框搬上来、翻历史、刚收优化结果），点了「→ 送进优化节点」就熄灭。
6. 后端**一行活都不干**：没有输出、不占排队，全部在前端画。

## 二·十五、附带的「模型池（多套模型并行）」节点（2026-11-03 起）

1. **为什么有它**：底模之间画风不同（比如 Anima 和 MOSS），要靠两套并行对比 —— 池子里每条记录 = **一个模型 + 它自己那套参数**，出图时各自加载、互不影响，画布上不额外摆空节点。
2. **一套 = 一竖列三框**（紫 MODEL / 黄 CLIP / 红 VAE）：把加载器节点**拖进面板**，按它输出的是 MODEL / CLIP / VAE **自动归位**；一个 Checkpoint 一次给三件，就三框全实。
3. 多套横向并排、按列数自适应；每套的 CLIP 类型 / 设备 / UNET 精度各自独立。**名字默认取第一个拖进来的节点名**，双击可改。
4. 模块右上角 ⚙：改别名、改参数、看状态圆点（没填的变灰），还能「↩ 吐回 MODEL/CLIP/VAE」把节点还回画布。最下面那颗「☐ 带 LoRA 池」决定这套出图时**要不要挂 LoRA 池**。
5. 输出 `MODEL` / `CLIP` / `VAE`；上面三个「可不连」输入口可以全连（透传）、也可以全不连（用池子里的）。

## 三、找不到节点 / 连不上时怎么查

| 症状 | 先查这几件事 |
|---|---|
| 节点菜单里找不到「提示词同步」 | ① 放的目录对不对（尤其秋叶整合包是不是放进了真正在跑的那份 `custom_nodes`）② 重启过 ComfyUI 没有 ③ 启动黑窗口有没有本节点的报错 ④ Ctrl+F5 强刷过没有 |
| 🔗 点开没反应、节点文本框不变 | ① ComfyUI 开着吗 ② 工具提示里给的端口对不对（不对就用 `-ComfyPort`）③ 节点装完重启过没有 ④ 看下面「四」的接口自己 curl 一下 |
| 提示「已连通」但点按钮文本不变 | 画布上的节点是「提示词同步（来自提示词工具）」吗（不是别的文本节点）；它是否在**当前这个**工作流里 |
| 模型别名不显示 | ① 节点是 2.0 吗（黑窗口那行会写版本号）② 重启过 ComfyUI 吗 ③ 是不是开了「Vue 节点」渲染模式（别名只在经典画布模式下显示）④ F12 有没有 `[游动羽翼工具栏]` 的提示 |
| 关键词权重改了，出图看不出变化 | ① 优化节点是不是**收起**状态（收起 = 文本不参与作图，权重自然也不生效）② 那个词在文本框里吗（表里有、框里没有的词只会**加到正提示词末尾**）③ 权重写 1 = 不加括号（等于没改）④ 优化节点是不是旧版（重启一次 ComfyUI 让它重新加载 `nodes.py`） |
| 点「▶ 开始排队」没反应 / 节点上写着红字 | ① 工具里推过这一套没有（节点上会写「已收到 0 段」）② 当前工作流里有没有「提示词同步（来自提示词工具）」节点 ③ 工作流里有没有输出节点（保存图片/预览那类）④ 节点后端是不是旧版（重启一次 ComfyUI） |
| 点「⏸ 暂停排队」写着「没什么可暂停的」 | 现在没有正在排的套图（它只在"排着"的时候有意义）；正在出图时按了暂停会先写「等这一张出完就停在这儿…」，出完才真的挂住 |
| 点「🗑 清除进程」被拒绝 | 正在出图时不许清（怕把这一轮弄成半吊子）—— 先点「⏸ 暂停排队」等这张出完、或「⏹ 停止」，再点清除；清完节点上会写「空闲 —— 等工具把这一套推过来」 |

## 四、接口（排错用）

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/prompt_sync/push` | 收下推送内容（启动器转发、或工具页面直连）并实时广播给浏览器 |
| GET | `/prompt_sync/current` | 取回最后一次推送 |
| GET | `/prompt_sync/ping` | 探活，工具/启动器用它判断节点是否已加载 |
| GET | `/prompt_sync/aliases` | 取整张模型别名表（1.4 起） |
| POST | `/prompt_sync/aliases` | 改一个别名 / 整张换掉 / 清空（写 `model_aliases.json`，1.4 起） |
| POST | `/prompt_sync/batch/push` | 工具把「🎞 套图」那一套（N 段）推过来（1.4 起） |
| GET | `/prompt_sync/batch/status` | 套图现在的状态（收到几段 / 排到第几张 / 休息还剩几秒，1.4 起） |
| POST | `/prompt_sync/batch/start` | 开排（body = 工作流 API 图 + 设置，1.4 起） |
| POST | `/prompt_sync/batch/stop` | 立刻停（1.4 起） |
| POST | `/prompt_sync/batch/pause` | 暂停 / 继续（body `{"paused":true/false}`，不给就取反；1.4 起）。正在出的那张不打断，等它出完才停 |
| POST | `/prompt_sync/batch/clear` | **清除进程**：收掉这一轮 + 清空工具推来的几段（只在暂停中 / 空闲时允许；正在出图会回 400 并说明） |

排错可以直接在浏览器里打开：`http://127.0.0.1:8188/prompt_sync/ping`，
看到 `{"success":true,"node":"PromptSync","version":"1.4"}` 就说明节点装好了、在跑、端口也对。

**跨源规则（2026-09-22 起）**：为了让**没配启动器**的工具（直接双击 HTML 打开的）也能互通，
本节点回 CORS 头，且**只放行本机来源**——不带 `Origin`（启动器转发）、`null` / `file://`（本地 HTML）、
`http(s)://127.0.0.1[:端口]`、`http(s)://localhost[:端口]`。别的网站拿不到 CORS 头，
预检就过不去，POST 根本发不出来。

## 五、行为约定（避免误会）

- **只写不空**：推送里没有负提示词时，**不会**动节点里已有的负提示词（不会把你的负词清空）。
- **手改优先**：工具只在"你点了按钮"时写入；你在 ComfyUI 里手改的内容不会被抢。
- **不走撤销栈**：直接写控件值不会进 ComfyUI 的原生撤销（Ctrl+Z 撤不回），这是写控件的固有行为。
- **多个节点**：如果画布上放了多个本节点，推送会写进**每一个**。
- **刷新页面**：刷新后文本框保持你保存工作流时的内容，不会被旧的推送覆盖。
