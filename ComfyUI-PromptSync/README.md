# 提示词同步（来自提示词工具）

ComfyUI 自定义节点：把桌面上的「提示词工具」和 ComfyUI 接起来。

在工具右上角打开 🔗 互通开关后，**点按钮就不再复制到剪贴板，而是直接把提示词写进本节点的文本框**；
如果那个按钮绑定了负提示词，正负会一起送过来，分别写进「正提示词」「负提示词」两个框。

---

## 一、安装

1. 把整个 `ComfyUI-PromptSync` 文件夹拷到：
   `ComfyUI\custom_nodes\ComfyUI-PromptSync`
2. **重启 ComfyUI**（必须）
3. 浏览器按 **Ctrl+F5** 强刷（自定义节点的 JS 会被缓存）

没有任何第三方 Python 依赖，不需要 pip install。

## 二、使用

1. 打开「提示词工具」（桌面快捷方式）
2. 点右上角的 **🔗** 打开互通开关
   - 提示「已连通 ComfyUI」= 一切就绪
   - 提示「ComfyUI 在运行，但还没加载互通节点」= 节点没装好或没重启
   - 提示「没找到运行中的 ComfyUI」= 8188 端口没在监听，此时点按钮会自动退回复制到剪贴板
3. 在 ComfyUI 里添加节点「**提示词同步（来自提示词工具）**」
4. 回工具里点任意按钮 → 节点的两个文本框当场更新

**输出怎么接**（两种都行）：

- **直接连线**：节点有两个输出「正提示词」「负提示词」，接给下游的文本节点即可（下游若是 CLIPTextEncode，需要把它的 text 控件右键「Convert Widget to Input」转成输入口才能接线）
- **手动粘贴**：不改工作流，直接把节点里的文本复制过去

**手动兜底**：节点上有一个「从工具同步一次」按钮，用于自动推送没生效时手动拉取最后一次内容。

## 三、行为约定（避免误会）

- **只写不空**：推送里没有负提示词时，**不会**动节点里已有的负提示词（不会把你的负词清空）。
- **手改优先**：工具只在"你点了按钮"时写入；你在 ComfyUI 里手改的内容不会被抢。
- **不走撤销栈**：直接写控件值不会进 ComfyUI 的原生撤销（Ctrl+Z 撤不回），这是写控件的固有行为。
- **多个节点**：如果画布上放了多个本节点，推送会写进**每一个**。
- **刷新页面**：刷新后文本框保持你保存工作流时的内容，不会被旧的推送覆盖。

## 四、接口（排错用）

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/prompt_sync/push` | 收下推送内容（由本地启动器在服务端调用）并实时广播给浏览器 |
| GET | `/prompt_sync/current` | 取回最后一次推送 |
| GET | `/prompt_sync/ping` | 探活，启动器用它判断节点是否已加载 |

跨站浏览器请求（`Sec-Fetch-Site: cross-site`）会被 403 拒绝；启动器的服务端转发不带该头，正常放行。
