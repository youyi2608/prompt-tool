# 提示词工具 · ComfyUI 节点包（1.4）

ComfyUI 自定义节点：把桌面上的「提示词工具」和 ComfyUI 接起来。

这个包里一共 **4 个节点**（三个中文、都不需要额外依赖）：

| 节点 | 分类 | 干什么 |
|---|---|---|
| 提示词同步（来自提示词工具） | `文本/提示词工具` | 工具推来的正/负提示词落在这里（本文件主要讲它） |
| 空Latent（自填宽高像素） | `latent/提示词工具` | 自己填长边/短边像素 + 横竖朝向（见「二·六」） |
| 游动羽翼工具栏 | `提示词工具` | 不工作的按钮面板：一键加本包节点 + 改模型别名（见「二·七」） |
| 套图排队（来自提示词工具） | `文本/提示词工具` | 一次排一整套提示词、中间自己休息，能暂停 / 继续 / 停止（见「二·八」） |

在工具左上角打开 🔗 互通开关后，**点按钮就不再复制到剪贴板，而是直接把提示词写进本节点的文本框**；
如果那个按钮绑定了负提示词，正负会一起送过来，分别写进「正提示词」「负提示词」两个框。

> **连不上？先看这一条（2026-09-24 加的）**：新版 ComfyUI 自带一层**跨源保护**
> （`server.py` 的 `origin_only_middleware`：只要请求头里 `Sec-Fetch-Site: cross-site` 就直接回 **403**）。
> 双击 HTML（`file://`）打开的页面，浏览器一定把它算成 cross-site → 于是**直连必然被 403 挡住**，
> 报错看起来像"节点没答话"，其实节点是好的。
> 两条路：① **推荐**——用本节点自带的「网页版工具」打开（见下面第五节）；
> ② 或者给 ComfyUI 启动参数加 `--enable-cors-header`（会放开那层保护，自己的机器上用完可以撤掉）。

---

## 一、安装

1. 把整个 `ComfyUI-PromptSync` 文件夹拷到**你正在用的那个 ComfyUI** 的 `custom_nodes\` 里：

   | 你用的是 | 该放进哪个目录 |
   |---|---|
   | 官方桌面版 / 便携版 | `…\ComfyUI\custom_nodes\ComfyUI-PromptSync` |
   | **秋叶整合包** | `…\ComfyUI-aki-vX\ComfyUI\custom_nodes\ComfyUI-PromptSync` |
   | 自己装的 | `<你的 ComfyUI 根目录>\custom_nodes\ComfyUI-PromptSync` |

   ⚠️ 整合包里常常有好几层 `ComfyUI` 目录（启动器一层、本体一层），**要放进真正在跑的那个**——
   放错了就会出现「找不到节点」。

2. **重启 ComfyUI**（必须）。重启时留意启动的黑窗口，如果本节点加载失败，那里会有报错。
   **怎么算装好了**：黑窗口的启动日志里应该出现这一行（1.2 起会打印）——
   `[提示词工具] ✅ 互通节点已加载（版本 1.3）：/prompt_sync/ping 可用`
   有这行 = 节点真的加载了；**没有这行**、或者出现 `[提示词工具] ⚠ …` = 没挂上，把那段报错发我。
   另一步：浏览器打开 `http://127.0.0.1:<端口>/prompt_sync/ping`，返回一小段 JSON 就是活着。
3. 浏览器按 **Ctrl+F5** 强刷（自定义节点的 JS 会被缓存）。

没有任何第三方 Python 依赖，不需要 pip install。

## 二、使用

1. 打开「提示词工具」（桌面快捷方式，**或者直接双击那个 HTML 都行**）
2. 点左上角的 **🔗** 打开互通开关
   - 提示「已连通 ComfyUI（127.0.0.1:8188）」= 一切就绪
   - 提示「ComfyUI 在运行，但还没装上互通节点」= 节点没装好或没重启
   - 提示「没找到在跑的 ComfyUI（试过端口 8188 / 8189 / …）」= 端口不对或 ComfyUI 没开，此时点按钮会自动退回复制到剪贴板
3. 在 ComfyUI 里添加节点「**提示词同步（来自提示词工具）**」
4. 回工具里点任意按钮 → 节点的两个文本框当场更新

工具会**自己找 ComfyUI 的端口**（8188 / 8189 / 8190 / 8000 / 8001 / 8080 挨个试）；
如果你的 ComfyUI 在这 6 个之外的端口（比如 9000），目前**自动探测到不了**——用启动器打开并加参数
`-ComfyPort 你的端口`，或者把 ComfyUI 换到上面任一个端口。

**输出怎么接**（两种都行）：

- **直接连线**：节点有两个输出「正提示词」「负提示词」，接给下游的文本节点即可（下游若是 CLIPTextEncode，需要把它的 text 控件右键「Convert Widget to Input」转成输入口才能接线）

⚠️ 节点顶上有一行灰字提示：**需要把 CLIP 文本编码节点的文本置空** —— 那个框里要是还留着老文本，
就和这里送过去的分不清到底用了哪个（不确定的话点开对应节点按一下清空）。
- **手动粘贴**：不改工作流，直接把节点里的文本复制过去

**手动兜底**：节点上有一个「从工具同步一次」按钮，用于自动推送没生效时手动拉取最后一次内容。

## 二·五、网页版工具（连不上时用这个，2026-09-24 加）

本节点附带一份**和桌面工具一模一样的网页版**，放在节点的 `web/prompt_tool.html`。
⚠️ **前端 js 和这个网页版放在同一个 `web/` 目录里**（2026-09-26 修）：ComfyUI 里一个节点模块**只会被挂载成一个 web 目录**（`nodes.py` 里 `EXTENSION_WEB_DIRS[module_name] = …`），以前 js 在 `./js`、网页版在 `./web`，挂载名只有一个 → `prompt_tool.html` 会 **404**（粉丝反馈的就是这个）。所以现在 `__init__.py` 里写的是 `WEB_DIRECTORY = "./web"`，两个文件一起挂出来。

ComfyUI 会把每个节点的 web 目录挂到 `/extensions/<节点文件夹名>/`，所以装好本节点并重启后，直接访问：

```
http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html
```

（端口按你实际的 ComfyUI 端口改；`ComfyUI-PromptSync` 要和你放进 `custom_nodes` 的文件夹名一致。）

**为什么推荐这条**：这个页面和 ComfyUI **同一个来源**，浏览器不会再把它当成"别的网站"，
ComfyUI 那层跨源保护（`Sec-Fetch-Site: cross-site → 403`）就不会触发，🔗 一定能连上。
注意：网页版的数据存在**它自己那个网址下**的浏览器里（和桌面那份不互通），
想用同一份数据的话，用「存档」导出一份、在另一边读进来即可。

## 二·六、附带的「空Latent（自填宽高像素）」节点（1.3 起）

同一个节点包里的第二个节点，跟提示词无关，纯粹是省事：**不用再记长宽像素、也不用猜尺寸下拉。**

| 排 | 控件 | 意思 |
|---|---|---|
| 1 | **长边像素** | 长边那条的像素数（默认 1152） |
| 2 | **短边像素** | 短边那条的像素数（默认 896） |
| 3 | **横边为长边还是短边** | 左右那条边用长边还是短边像素数（默认 长边） |
| 4 | **竖边为长边还是短边** | 上下那条边用长边还是短边像素数（默认 短边） |
| 5 | **数量** | 一次生成几张 |

这样"现在是横图还是竖图"是**你自己指定**的，不用去猜别的预设节点下拉里那个尺寸（它们的毛病就是分不清横竖、还全是英文）。
像素数不是 8 的倍数时向下取整（latent 只能是 1/8）；两条边都选同一条（比如都选「长边」）就老老实实出 **1152×1152 正方形**，不会替你改。两条默认值出来就是横图 1152×896。

节点在分类 **`latent/提示词工具`** 下，名字「**空Latent（自填宽高像素）**」，输出一个 LATENT，直接接采样器即可。

## 二·七、附带的「游动羽翼工具栏」节点 + 模型别名（1.4 起）

分类 **`提示词工具`** 下的第三个节点。**它不参与工作流**：没有输入输出、也不是输出节点，
ComfyUI 永远不会执行它、也不占排队 —— 就是画布上的一块按钮面板。

**功能一 · 一键把本包自己的节点叫出来**：面板上有个下拉列出本包的节点（提示词同步 / 空Latent …），
选好点「➕ 加到画布」，节点就落在画布正中间（省得在搜索框里翻）。

**功能二 · 模型别名**：LoRA / Checkpoint / VAE / UNet / CLIP / ControlNet 这些下拉里的文件名，
可以给它们记一个你认得出的别名：

- 画布上显示**别名**（带灰底），下拉列表里显示的也是别名，**鼠标停在上面才显示真名**；
- **文件一个都不改**，下拉里选中的、工作流和 API 图里存的、ComfyUI 真正加载的，全都是**真文件名** ——
  所以分享工作流 / 换台机器都不会因为"我改过名"而对不上；
- 别名只存在本机节点文件夹里的 `model_aliases.json`（纯 JSON，可以直接手改、也可以拷给别人）：
  `{ "loras/bantan-step00007000.safetensors": "悠悠画风" }`，键 = `种类/下拉里的相对路径`。

**怎么改别名**（刻意**不做**"把上千个文件列成一个下拉"那种界面）：

1. 点面板上的「✎ 模型别名」→ 面板里「画布上的模型栏位」那一段列出你**当前工作流里真正在用的**那几个，点行尾的 ✎ 直接改；
2. 或者点「✎ 点一下画布改名」→ 画布上所有模型下拉会亮起黄框 → **点你要改的那个** → 填别名 → 保存（Esc 退出）；
3. 面板最下面「已经改过别名的」只列你改过的那些，可以再改、可以删（删 = 恢复真名）。

⚠️ 「点选改名」用的是 ComfyUI 前端自己的机制（`options.getOptionLabel` / 控件实例的 `background_color` /
`onClick`），**核对的版本是 comfyui_frontend 1.45.21**。如果哪天 ComfyUI 大改前端结构、别名突然不显示了，
去 F12 Console 看有没有 `[游动羽翼工具栏]` 开头的提示；改别名那个管理面板是稳的那一半（它只读写 JSON）。

## 二·八、附带的「套图排队（来自提示词工具）」节点（1.4 起）

分类 **`文本/提示词工具`** 下的第四个节点，跟「提示词同步」**完全独立**（两种不同用法，各管各的）：
那个是"推一次出一次"，这个是**一次排一整套、中间自己等**。它自己也**不参与工作流、不会被执行**。

**三排控件**：

| 排 | 控件 | 意思 |
|---|---|---|
| 1 | **每张之间休息(秒)** | 每张图之间歇多久，默认 **60**（0~600）。官方建议别低于 60 秒 |
| 2 | **一次最多几张** | 这一轮最多排几张，默认 **4**（工具一次最多送 4 段，这里再兜一层） |
| 3 | **每张换随机种子** | 开着的话每张都把工作流里的 `seed` / `noise_seed` 换一个随机值 |

⚠️ 节点顶上有一行灰字提示：**需要和「提示词同步」节点一起使用** —— 这一套提示词是**那个节点**送出去的，
少了它这套排了也不会出图。（同理，「提示词同步」节点顶上写着：**需要把 CLIP 文本编码节点的文本置空**。）

**怎么用**：先在「提示词工具」里点 **🎞 套图** 把这一套（最多 4 段，每段可带备注）推给节点 →
在 ComfyUI 里点节点上的 **「▶ 开始排队」**（节点前端会把**当前工作流**的 API 图一起发过去）→
后端一张一张排；想暂停就点 **「⏸ 暂停排队」**（同一颗键会变成 **「▶ 继续排队」**）；
想停就点 **「⏹ 停止」**（= 不再排下一张 + 收掉还没开始的 + 打断正在跑的那张）；
想**清掉这一轮重来**就点 **「🗑 清除进程」**（= 收掉这一轮 + 清空工具推过来的那几段，回到"等工具再推一次"——
**暂停中或还没开始的时候才让清**，正在出图时它会告诉你先按暂停/停止）。
节点身上会写着：`已收到 4 段 · 本轮 1/2 张 · 已出 1 张` / `正在休息 18 秒（这段时间 ComfyUI 是空的）…` /
`已暂停 —— 点「▶ 继续排队」接着排（已经出的图都在）`。

**暂停的规矩**：正在出的那一张**不打断**，等它出完才停在那儿（节点上会先写
「已按下暂停 —— 等这一张出完就停在这儿…」）；休息里按暂停就是立刻挂住，恢复后把剩下的几秒走完再排下一张。

**内部怎么做的**（排错时有用）：休息**在 ComfyUI 队列外面**，靠节点后端一个喂饭线程：

```
排第 1 张 → 等它出完（轮询这个 prompt_id 的 history）→ 睡 N 秒（分片睡、随时可停 / 可暂停）→ 再排下一张
```

- 换的是工作流里 **「提示词同步」节点的 `positive` / `negative`**，其余节点一个字节不改；
- 顺手把那个节点的标题改成你的备注（`套图 i/n`），这样 ComfyUI 的队列面板里一眼看得出排到哪张；
- 因为休息时队列是空的，**这时候点「⏹ 停止」是立刻停的**；正在出图时点会打断当前那张。
- 暂停落在"两张之间"（这张刚出完 / 正在休息）—— 这也是为什么不会出现"图出到一半被掐掉"。

## 三、找不到节点 / 连不上时怎么查

| 症状 | 先查这几件事 |
|---|---|
| 节点菜单里找不到「提示词同步」 | ① 放的目录对不对（尤其秋叶整合包是不是放进了真正在跑的那份 `custom_nodes`）② 重启过 ComfyUI 没有 ③ 启动黑窗口有没有本节点的报错 ④ Ctrl+F5 强刷过没有 |
| 🔗 点开没反应、节点文本框不变 | ① ComfyUI 开着吗 ② 工具提示里给的端口对不对（不对就用 `-ComfyPort`）③ 节点装完重启过没有 ④ 看下面「四」的接口自己 curl 一下 |
| 提示「已连通」但点按钮文本不变 | 画布上的节点是「提示词同步（来自提示词工具）」吗（不是别的文本节点）；它是否在**当前这个**工作流里 |
| 模型别名不显示 | ① 节点是 1.4 吗（黑窗口那行会写版本号）② 重启过 ComfyUI 吗 ③ 是不是开了「Vue 节点」渲染模式（别名只在经典画布模式下显示）④ F12 有没有 `[游动羽翼工具栏]` 的提示 |
| 点「▶ 开始排队」没反应 / 节点上写着红字 | ① 工具里推过这一套没有（节点上会写「已收到 0 段」）② 当前工作流里有没有「提示词同步（来自提示词工具）」节点 ③ 工作流里有没有输出节点（保存图片/预览那类）④ 节点后端是不是旧版（重启一次 ComfyUI） |
| 点「⏸ 暂停排队」写着「没什么可暂停的」 | 现在没有正在排的套图（它只在"排着"的时候有意义）；正在出图时按了暂停会先写「等这一张出完就停在这儿…」，出完才真的挂住 |
| 点「🗑 清除进程」被拒绝 | 正在出图时不许清（怕把这一轮弄成半吊子）—— 先点「⏸ 暂停排队」等这张出完、或「⏹ 停止」，再点清除；清完节点上会写「空闲 —— 等工具把这一套推过来」 |

## 四、接口（排错用）

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/prompt_sync/push` | 收下推送内容（启动器转发、或工具页面直连）并实时广播给浏览器 |
| GET | `/prompt_sync/current` | 取回最后一次推送 |
| GET | `/prompt_sync/ping` | 探活，工具/启动器用它判断节点是否已加载 |
| GET | `/prompt_sync/aliases` | 取整张模型别名表（1.4 起） |
| POST | `/prompt_sync/aliases` | 改一个别名 / 整张换掉 / 清空（写 `model_aliases.json`，1.4 起） |
| POST | `/prompt_sync/batch/push` | 工具把「🎞 套图」那一套（N 段）推过来（1.4 起） |
| GET | `/prompt_sync/batch/status` | 套图现在的状态（收到几段 / 排到第几张 / 休息还剩几秒，1.4 起） |
| POST | `/prompt_sync/batch/start` | 开排（body = 工作流 API 图 + 设置，1.4 起） |
| POST | `/prompt_sync/batch/stop` | 立刻停（1.4 起） |
| POST | `/prompt_sync/batch/pause` | 暂停 / 继续（body `{"paused":true/false}`，不给就取反；1.4 起）。正在出的那张不打断，等它出完才停 |
| POST | `/prompt_sync/batch/clear` | **清除进程**：收掉这一轮 + 清空工具推来的几段（只在暂停中 / 空闲时允许；正在出图会回 400 并说明） |

排错可以直接在浏览器里打开：`http://127.0.0.1:8188/prompt_sync/ping`，
看到 `{"success":true,"node":"PromptSync","version":"1.4"}` 就说明节点装好了、在跑、端口也对。

**跨源规则（2026-09-22 起）**：为了让**没配启动器**的工具（直接双击 HTML 打开的）也能互通，
本节点回 CORS 头，且**只放行本机来源**——不带 `Origin`（启动器转发）、`null` / `file://`（本地 HTML）、
`http(s)://127.0.0.1[:端口]`、`http(s)://localhost[:端口]`。别的网站拿不到 CORS 头，
预检就过不去，POST 根本发不出来。

## 五、行为约定（避免误会）

- **只写不空**：推送里没有负提示词时，**不会**动节点里已有的负提示词（不会把你的负词清空）。
- **手改优先**：工具只在"你点了按钮"时写入；你在 ComfyUI 里手改的内容不会被抢。
- **不走撤销栈**：直接写控件值不会进 ComfyUI 的原生撤销（Ctrl+Z 撤不回），这是写控件的固有行为。
- **多个节点**：如果画布上放了多个本节点，推送会写进**每一个**。
- **刷新页面**：刷新后文本框保持你保存工作流时的内容，不会被旧的推送覆盖。
