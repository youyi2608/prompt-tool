提示词工具 5.0 正式版 · 使用说明
=================================

一个给 ComfyUI 用的提示词「编撰 / 组装 / 复制 / 一键推送」工具。
单文件 HTML —— 双击就能用，不用安装、不用联网，数据存在你自己电脑上。

⚠️ 三个关键提示（先看这个）
  1. 点按钮 = 复制（左上角 🔗 打开时 = 直接推给 ComfyUI，不再复制）
  2. 词库只要导一次，以后刷新 / 重开都自动在
  3. 数据一定记得用「存档」留一份 json（尤其你是双击 HTML 打开的时候）

==================================================
一、包里有什么（7 样）
==================================================
1. 提示词工具.html      ← 双击它就能用
2. 词库.bmz             ← 32 万条词库（加密单文件，6.75MB），第一次用导一次
3. ComfyUI-PromptSync\  ← ComfyUI 互通节点（可选；里面还带一份「网页版工具」）
4. 存档4_示例初级_20260920.json  ← 示例存档（想直接看效果就导入它）
5. 示例设置代码.txt     ← 示例界面布局（43 个字符）
6. 私发说明.txt         ← 更细的上手说明
7. 连接排查.txt         ← 连不上 ComfyUI 就看它（另有《连不上_案例记录.txt》是完整案例）

==================================================
二、上手三步（约 3 分钟）
==================================================
1. 双击「提示词工具.html」（建议 Chrome / Edge）
2. 右上角「读档」→「📂 手动读档」→ 选 存档4_示例初级_20260920.json
   （想让界面也跟示例一样：设置 → 布局代码 → 粘贴 示例设置代码.txt 里的内容 → 导入）
3. 装词库：右上角切到「拼装」→ 点「📦 词库包」（模式一在右栏；模式二在搜索栏那一排右边）
   → 选 词库.bmz → 等 1~2 秒
   有启动器时它会写进 桌面\工作流\词库\；直接双击 HTML 时存进浏览器自己的库里
   —— 两种都是「导入一次，下次打开就不用再导」

==================================================
三、ComfyUI 互通（可选，推荐）
==================================================
1. 把 ComfyUI-PromptSync 整个文件夹拷进 ComfyUI 的 custom_nodes\，重启 ComfyUI
   · 官方便携版：…\ComfyUI_windows_portable\ComfyUI\custom_nodes\
   · 秋叶整合包：…\ComfyUI-aki-vX\ComfyUI\custom_nodes\
2. 看 ComfyUI 黑窗口里有没有这行：
      [提示词工具] ✅ 互通节点已加载（版本 1.2）：/prompt_sync/ping 可用
3. 工具顶栏左上角点亮 🔗 → 之后点按钮就把正 / 负提示词直接写进节点文本框

⚠️ 连不上时先做这一步：浏览器打开 http://127.0.0.1:<端口>/prompt_sync/ping
   · 返回一段 JSON（有 "success": true）→ 节点是好的！那就是**新版 ComfyUI 的跨源保护**把
     双击 HTML 打开的页面当成"别的网站"拦了（F12 里是 403）。解决办法：重启一次 ComfyUI，
     然后改用网页版打开：
         http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html
     （和 ComfyUI 同一个来源，一定能连上；数据存在它自己那个网址下，要搬就用存档导出/导入）
     或者给 ComfyUI 启动参数加 --enable-cors-header 后重启（等于放开那层保护，用完可删）
   · 显示 404 / Not Found → 节点真没加载：看黑窗口那行，并确认整个文件夹放对了、重启过
   详细步骤见《连接排查.txt》第 0·5 步；完整案例见《连不上_案例记录.txt》。

==================================================
四、数据存在哪（重要）
==================================================
· 用桌面快捷方式（启动器）打开：主数据 = 桌面\工作流\提示词数据.json，
  每次改动前自动备份到 桌面\工作流\数据自动备份\（每天最早一份 + 每次一份，各留 30 份）
· 直接双击 HTML 打开：数据在**你浏览器里** —— 清浏览器数据就没了，请用「存档」存成 json
· 「存档」那 5 个手动档位 = 你自己选位置的 json 文件；第 6 档自动存档在浏览器里
