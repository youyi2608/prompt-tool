🎉 提示词工具 6.0 正式版更新公告 · 2026-10-02

这一版东西比较多，慢慢看 —— 方向都是"少记一点、少点几下"。

## 一、拼装模式二，更像网页了 🧩

### 1. 分组与排序四档

设置里单独一栏（不再挤在勾选网格里）：有分类（不智能排序 / 分类内智能排序）、标签即分类、无分类平铺。四档随时切换，选哪档都记得住。

### 2. 能少点一次就少点一次
- 搜索结果分两段：本类的结果 + 「其他分类里还有 N 条」——有多少条直接写在界面上，不用先点一下才知道；
- 设置里那些占地方的长解释，收成一颗「!」小圆钮：点一下、或者鼠标停 0.7 秒就弹出来。

## 二、API 面板变成聊天框了 💬
- 弹窗放大到和「🎲 随机抽卡」一个尺寸；左边一排是 AI 配置（像聊天软件的好友列表，点一下切换，可以存好几套）——旧配置会自动整套搬进来，密钥一个都不丢；
- 顶上那块「数据摘要」能拖着收起来，看画布的时候不占地方；
- AI 的回答就在气泡里，旁边两颗键：👀 预览 / ⚡ 执行；撤回上一步时，那条会自己变成「已撤回」；
- 灰字直接写明：AI 没有记忆，聊天记录只是备忘录、往上一段段加载。

## 三、ComfyUI 那边多了两件新东西 🧰

### 1. 「游动羽翼工具栏」节点
- 一键把本包的节点加到画布正中间，不用在几百个节点里翻名字；
- 模型别名：给 Checkpoint / LoRA / VAE… 那些下拉栏换一个顺眼的名字 —— 显示的是别名，文件名一个都不动（工作流和分享完全不受影响）。别名也在 ComfyUI 里改，点一下画布上那个下拉就行。
- 节点上还有一颗 🌐 打开提示词工具：直接从 ComfyUI 里打开这个工具的同源网页版（和数据完全互通，最不容易连不上）；「提示词同步」节点顶上另有一行灰字，提醒把 CLIP 文本编码节点的文本置空。

### 2. 「套图排队」节点 + 工具里的「套图生成」面板
- 一次排一整套：几个方框各放一组正 / 负提示词，每张之间休息 N 秒（默认 60，低于 60 只给琥珀色提醒、不拦你）；
- 加词两条路：把页面里的按钮拖进某个框（或拖到顶上那两条虚线 = 所有框都加），也可以点虚线进选择模式、连着点几个按钮；负提示词那一栏也能直接拖进来；
- 节点上多了 「⏸ 暂停排队」：按下去就挂起，正在出的那一张会先出完（不会把图掐断），同一颗键变成「▶ 继续排队」，接着往下排；休息时按暂停则是立刻停在这儿；
- 休息是在队列外面等的 —— 休息期间 ComfyUI 是空闲的，随时能停、随时能暂停。

## 四、顺手修掉的、变好看的地方 ✨
- 「空Latent（自填宽高像素）」：长边 / 短边自己填，节点上直接画一个等比矩形告诉你是横置还是竖放，还有一颗「⇄ 对调横竖」；
- 内容分级：按你自己打的 16+ / NSFW 标签过滤，新手期自动只显示安全的，计数不扣；
- 黑夜 / 白天切换两档过渡（水波 / 平滑淡入），设置里可选；
- 三条贴底栏（购物车 / 套图生成 / 负提示词）的拖动键统一成一个样子；收起后是左下角一个小书页标签，点一下原样拉回、右上角的 ✕ 关掉、长按还能拖到别处；
- 负提示词按住 0.5 秒就能上下拖着调顺序：拖起来的那条留在原地变淡，虚线框停在"松手就放这里"的那一格；拖着的时候也不会再选中文字了；
- 「API」「套图」两颗小圆钮换了一套安静的特效（一圈静态细环 + 一道极慢扫过去的弧光，不呼吸、不闪）；
- 各种"失败提示"分得更细：是哪一环断了、下一步做什么，都写在提示里。

## 五、这一版还带了什么 📦

ComfyUI 节点包升到 1.4（提示词同步 / 空Latent / 游动羽翼工具栏 / 套图排队，一共四个节点），词库与示例存档一并更新；分享包里三个 LoRA 全部改回 Civitai 上的发布原名，方便你和别人核对文件。

另外，打包版第一次打开会问你一句「要不要导入随包附带的示例存档」（不用再自己翻「读档」在哪），按「确定」就直接装上一套现成的按钮和负提示词，按「取消」就从空白开始、以后也不再问。
