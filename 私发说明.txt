二、最快的上手三步（大约 3 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 双击「提示词工具.html」→ 第一次打开会自动套上新手布局（右上角一颗颗小按钮）。
2. 词库：**第一次打开自动装好**（加密词库内嵌在 HTML 里，什么都不用点）；要换/更新再点「拼装 → 📦 词库包」→ 选「翻译库存档」里的「词库.bmz」
   → 等 1~2 秒，提示「词库包导入完成：大词表 324,470 条 · 共现表 … · 标签分类 …」就成了。
   ⚠️ 只需要导这一次：没有启动器时它会存进你自己浏览器里，以后刷新、重开都自动在；
      只有「换浏览器」或者「清了浏览器数据」才需要重导。
3. 想看一整套效果：设置 → 读档 → 选「数据存档\示例存档安全版.bmz」（加密存档包，直接选就行）；

三、这次 7.0 重点麻烦你试这几样
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【先试这些】
· 右下角「套图」：一整套提示词编好、一次推给 ComfyUI 一张一张出。按钮**拖**进方框（拖到顶上那两条虚线
  = 所有框都加），或者点虚线进选择模式连着点几个；负提示词那一栏也能直接拖进来。推完去 ComfyUI 的
  「套图排队」节点点「▶ 开始排队」；那颗「⏸ 暂停排队」按下去**会在这一张出完之后才停**，同一颗键变「▶ 继续排队」。
· 右上角「设置 → 界面显示」里的「**分组与排序四档**」：随时换显示方式，选哪档都记得住。
· 右下角「API」：面板里就两件事 —— ①「📋 数据摘要」把按钮 / 分类 / 标签 / 负词 / 分页 + 统计打包成一份
  只读快照，复制或「💾 导出成文件」丢给任意 AI 看（能**拖着收起来**）；②「📊 统计判断」直接看数字：谁反复出现、
  标签谁用得最多、哪些按钮没分类 / 没标签、提示词平均与最长多长（点高频词复制，点标签进那个标签页）。
  ⚠️ 摘要和统计都是**快照**，改了数据点「🔄 刷新」看最新的。
· 负提示词那一栏：**按住一条 0.5 秒**能拖着调顺序（虚线框停的那格就是松手后它去的位置），
  拖着的时候不会再选中文字了。
· 打包版**第一次打开**会问你一句「要不要导入随包附带的数据存档」：按确定就直接装一套现成的按钮 + 负提示词，
  按取消就从空白开始（以后不再问）。自己原来的存档不会被顶掉（导入永远不覆盖，重名自动加 -1）。
· ComfyUI 那边的「游动羽翼工具栏」节点上多了颗「🌐 打开提示词工具」——从 ComfyUI 里直接打开**同源网页版**，
  连不上时走这条最稳。

【底下这些 5.1 就有，第一次用还是从这儿看起】
（右上角切到「拼装」→ 上面那排页签选「模式二」）

1. 顶部五大类（角色 / 穿搭 / 画面全局 / 头部神态 / 形体）像网页导航一样五等分，点着换。
2. 每个大类里点一个小分类（比如 穿搭 → 上装）就有词条，是密密的小圆片；
   点一下 = **进购物车**（不是复制），底下的购物车条会自己出来。
3. 购物车条：
   · 上边缘能**按住上下拖**，调高度（会记住你拖的高度）
   · 车里的词条也能**拖着调顺序**
   · 「复制全部」= 把车里的词一次复制出来（模式二用的是逗号连接的紧凑格式）
   · 「💾 存为成套」= 把这一车存成一个按钮，回头能当"组合选项"用
   · **两个模式的购物车是分开的**：复制模式那辆车和模式二这辆车互不影响
   · 车里没有词的时候车条不会占地方；在复制模式点右下角 🛒 会立刻弹出来
4. 组合选项：在**复制模式**里点某个按钮的「编辑」→ 把「组合选项」选成 一个大类 → 那个大类的
   组合选项区就会出现它。点一下 = **用这一套替换这个大类已经选的词，然后自动跳到下一个大类**。
   指了组合选项的按钮，卡片左上角会露一个**小金星**。
5. 搜索框（按回车或者点「🔍 搜索」）：空格 = 有任一、`+` = 同时含、`-` 前缀 = 排除；
   结果会分「本类」和「其他分类里还有 N 条」两段。
6. 词条往下滑、或者点「往下滑或者点击继续加载」都能加载；到 500 条以后还能继续，
   最前面那 100 条会自动折起来（列表顶部有「点这里再展开」）。
7. **特别想让你反馈的**：哪些地方你会不自觉地想去点、结果点错了 / 没反应；
   以及哪些字看不清楚（尤其黑夜模式下）。

四、ComfyUI 互通（可选，不玩 ComfyUI 就跳过）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 把「ComfyUI-PromptSync」整个文件夹拷进**你正在用的那个 ComfyUI** 的 custom_nodes\ 目录
   —— 秋叶整合包一般在 …\ComfyUI-aki-vX\ComfyUI\custom_nodes\（注意别拷错那一层）
2. 重启 ComfyUI，浏览器里 Ctrl+F5 刷一下
3. 自查最快的一步：浏览器打开 http://127.0.0.1:8188/prompt_sync/ping
   （8188 换成你自己的端口）—— 有东西返回就说明节点活着
   ⚠️ 端口只在 8188 / 8189 / 8190 / 8000 / 8001 / 8080 里自动找；你的 ComfyUI 要是改了
      别的端口，直接把端口号告诉我（没有启动器时工具自己改不了这个列表）
      不确定自己是哪个端口？看 ComfyUI 那个黑窗口，开头有一行
      「To see the GUI go to: http://127.0.0.1:xxxx」，那个 xxxx 就是端口
4. 工具顶栏**左上角**那颗「🔗」打开 → 之后「复制全部」会直接把提示词推进 ComfyUI
5. 连不上不用猜，工具会直接告诉你卡在哪一环：
   · 「没找到在跑的 ComfyUI（试过端口 …）」= ComfyUI 没启动（或端口不在上面那 6 个里）
   · 「检测到 ComfyUI 在 127.0.0.1:8188 上跑着，但互通节点没答话」= ComfyUI 开着，但节点没装好
     → 去检查 custom_nodes\ComfyUI-PromptSync 这一层（要**整个文件夹**，不能只拷里面的文件），
       弄好之后**重启 ComfyUI**（关掉黑窗口再重新跑一遍 run_nvidia_gpu.bat）
     → **怎么确认真装上了**：看 ComfyUI 那个黑窗口，启动那几行里应该有一条
       「[提示词工具] ✅ 互通节点已加载（版本 2.0）：/prompt_sync/ping 可用」
       有这行 = 节点真的加载了；**没有这行**（或者有 ⚠ 报错）= 没加载成功，
       把黑窗口里那几行（连同报错）截图/复制给我
   · 浏览器打开 http://127.0.0.1:8188/prompt_sync/ping 是 **404** = 节点没被加载；
     能返回一小段 JSON = 节点活着（那工具还连不上就把这个结果告诉我）
   · 「连上了 127.0.0.1:8188 但没推成功」= 节点刚重启过，再点一次就行
   · ⚠️ **新版 ComfyUI 会"不让别的网页访问它"**（2026-04 起加了跨源保护，浏览器控制台里是 `403 (Forbidden)`）：
     双击 HTML 打开的工具在新版上会**一定**被挡住，哪怕节点装得好好的。这时用节点自带的**网页版工具**：
     重启一次 ComfyUI，然后浏览器打开
         http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html
     （和 ComfyUI 同一个来源，🔗 一定连得上；数据存在它自己那个网址下，想搬就先用存档导出）
     或者给 ComfyUI 启动参数加 `--enable-cors-header` 后重启（等于放开那层保护，用完可删）。
     详细步骤见同目录的 **`连接排查.txt` 第 0·5 步**。
6. 右下角那颗 **「API」** 小圆钮（4.3 起就有）：点开是**两件事** ——
   · **📋 数据摘要**：把你现在的按钮 / 分类 / 标签 / 负提示词 / 分页 + 一份统计打包成**只读快照**，
     点「📋 复制」贴给任意 AI（网页版、手机上都能用），或者「💾 导出成文件」把文件直接拖进 AI 对话框。
     它不是实时的：改了数据想立刻看最新的就点「🔄 刷新」（复制 / 导出之前都会自动重算）。
   · **📊 统计判断**：不用问 AI，直接看数字 —— 反复出现的词（≥2 次，点一下复制这个词）、标签用量
     （点一下进那个标签页，看带它的所有按钮）、没分类 / 没标签的按钮有几颗、提示词平均与最长多长。
   ⚠️ 面板**左边栏**是 **AI 配置**（能存好几套、点一下切换）；**聊天对话与「行动代码」那套没有恢复**，
     所以右栏就是数据摘要 + 统计判断。想让它帮你改数据，就把摘要交给任意 AI 出主意、自己在工具里落地。

    存在浏览器里，默认每 5 分钟一次（设置里能改成 1~30 分钟）。
    「套图文件」（套图栏那颗「📂 套图文件」）也一样：存在 `桌面\工作流\数据\套图文件\`，最多 10 个、名字随你起。
  - **直接双击 HTML** 打开时（没有启动器）：数据存在**你这台电脑的浏览器里**，想留文件就用上面那些
    存档位存成 json —— 千万别清浏览器数据，清了就没了。

  认出词表内容**，不是防人。
· 这是 **8.5 正式版**，功能以你手上这份为准。
