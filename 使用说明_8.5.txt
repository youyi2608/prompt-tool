提示词工具 8.5 正式版 · 使用说明
=================================


⚠ 这个文件夹请放在【桌面】上，而且别改文件夹名字。
  原因：提示词工具把「图片存档」写在 桌面\工具 8.5 正式版\图片存档，
  启动器的词库目录也在 桌面\工作流\词库 —— 换地方或者改名字，图就存不到包旁边了。

一个给 ComfyUI 用的提示词「编撰 / 组装 / 复制 / 一键推送」工具。
单文件 HTML —— 双击就能用，不用安装、不用联网，数据存在你自己电脑上。

⚠️ 三个关键提示（先看这个）
  1. 点按钮 = 复制（左上角 🔗 打开时 = 直接推给 ComfyUI，不再复制）
  2. 词库只要导一次，以后刷新 / 重开都自动在
  3. 数据一定记得用「存档」留一份 json（尤其你是双击 HTML 打开的时候）

==================================================
一、包里有什么（7 样，见下）
==================================================
1. 提示词工具.html      ← 双击它就能用
2. 翻译库存档\词库.bmz ← 32 万条词库（加密单文件，6.75MB），第一次用导一次
3. ComfyUI-PromptSync\  ← ComfyUI 互通节点（可选；里面还带一份「网页版工具」）
4. 数据存档\示例存档安全版.bmz ← 数据存档（**加密存档包**，140 个按钮 / 68 条负词的完整实例；「手动读档」直接选它）。文件名带 **`.bmz`** 是因为**有些网盘会把 `.pcs` 判成违规文件滤掉** —— 内容和 `.pcs` 一模一样，工具按文件头识别、不看扩展名
5. 8.5工作流.json      ← 出图工作流（直接拖进 ComfyUI 界面）
6. 使用说明_8.5.txt / 更新公告_8.5.txt / README.md ← 就是这几份
7. 私发说明.txt         ← 更细的上手说明

==================================================
二、上手三步（约 3 分钟）
==================================================
1. 双击「提示词工具.html」（建议 Chrome / Edge）
2. 右上角「读档」→「📂 手动读档」→ 选 数据存档\示例存档安全版.bmz
3. 装词库：右上角切到「拼装」→ 点「📦 词库包」（模式一在右栏；模式二在搜索栏那一排右边）
   → 一般不用做这一步：**包版第一次打开会自动装好词库**；只有想换一份时，才进「翻译库存档」选 词库.bmz → 等 1~2 秒
   有启动器时它会写进 桌面\工作流\词库\；直接双击 HTML 时存进浏览器自己的库里
   —— 两种都是「导入一次，下次打开就不用再导」

==================================================
三、ComfyUI 互通（可选，推荐）
==================================================
1. 把 ComfyUI-PromptSync 整个文件夹拷进 ComfyUI 的 custom_nodes\，重启 ComfyUI
   · 官方便携版：…\ComfyUI_windows_portable\ComfyUI\custom_nodes\
   · 秋叶整合包：…\ComfyUI-aki-vX\ComfyUI\custom_nodes\
2. 看 ComfyUI 黑窗口里有没有这行：
      [提示词工具] ✅ 互通节点已加载（版本 2.0）：/prompt_sync/ping 可用
3. 工具顶栏左上角点亮 🔗 → 之后点按钮就把正 / 负提示词直接写进节点文本框

⚠️ 连不上时先做这一步：浏览器打开 http://127.0.0.1:<端口>/prompt_sync/ping
   · 返回一段 JSON（有 "success": true）→ 节点是好的！那就是**新版 ComfyUI 的跨源保护**把
     双击 HTML 打开的页面当成"别的网站"拦了（F12 里是 403）。解决办法：重启一次 ComfyUI，
     然后改用网页版打开：
         http://127.0.0.1:8188/extensions/ComfyUI-PromptSync/prompt_tool.html
     （和 ComfyUI 同一个来源，一定能连上；数据存在它自己那个网址下，要搬就用存档导出/导入）
     或者给 ComfyUI 启动参数加 --enable-cors-header 后重启（等于放开那层保护，用完可删）
   · 显示 404 / Not Found → 节点真没加载：看黑窗口那行，并确认整个文件夹放对了、重启过

==================================================
三·五、这 12 颗节点各是干什么的（一句话版）
==================================================
（想连线就打开 ComfyUI 里那颗「游动羽翼工具栏」上的「📖 说明书」，那里有"哪根线接哪"的图）

 1 提示词同步（来自提示词工具）   工具推过来的正负词落这儿；两个输出口，只接一个也行
 2 CLIP 文本编码优化节点        正负二合一；接了「提示词同步」就用口里那份，没接就用框里写的
 3 关键词权重（附属节点）        调某个词的权重，只改"送去编码的那份"，不动你框里的字
 4 空Latent（自填宽高像素）      自己填长边/短边像素，节点上画着等比矩形预览
 5 游动羽翼工具栏              画布上的按钮盘：加节点 / 开说明书 / 改模型别名 / 开工具 / 小字橡皮擦
 6 套图排队（来自提示词工具）    工具里推一整套 → 节点上一张张排队出图，能暂停继续
 7 计时器（休息计时 + 生图效率）  黄条读制图、灰条读休息，到点响一声；另有独立桌面浮窗
 8 LoRA 池                     把 LoraLoader 拖进去吃掉；点一下=暂时不参与，亮着的才叠
 9 自定义优化窗（节点）          写要求 → 工具那边跑 AI → 结果写回优化节点（工具得开着）
10 图像画廊（展示 + 存档）       代替预览节点，出图自动存档；能请神复现、复制、局部重绘
11 暂存节点（下一批文本）        一边出图一边攒下一批稿子，满意了再顶上去
12 模型池（多套模型并行）        几套模型并排（比如 Anima + MOSS），各自参数互不影响

==================================================
四、数据存在哪（重要）
==================================================
· 用桌面快捷方式（启动器）打开：主数据 = 桌面\工作流\提示词数据.json，
  每次改动前自动备份到 桌面\工作流\数据自动备份\（每天最早一份 + 每次一份，各留 30 份）
· 直接双击 HTML 打开：数据在**你浏览器里** —— 清浏览器数据就没了，请用「存档」存成 json
· 「存档」那 5 个手动档位：**用桌面快捷方式（启动器）打开时，直接存进 `桌面\工作流\数据\存档\`，不用你再挑路径**；
  直接双击 HTML 打开（没有启动器）时才会弹保存框让你选位置。第 6 档自动存档在浏览器里
· 「套图文件」（套图栏那颗「📂 套图文件」）：存在 `桌面\工作流\数据\套图文件\`，**最多 10 个**、名字随你起

==================================================
五、8.5 里加 / 改了什么（怎么用）
==================================================
【画布上的新节点】
· 模型池（多套模型并行）：一竖列三框 = 紫 MODEL / 黄 CLIP / 红 VAE。把加载器节点**拖进面板**就归位；
  几条竖列 = 几套模型，各套参数独立（CLIP 类型 / 设备 / UNET 精度）。名字取第一个拖进来的节点名，双击能改；
  模块右上角 ⚙ 里能改别名、能把节点「吐回画布」、能勾「带 LoRA 池」。
· 暂存节点（下一批文本）：上框 = 现在用的、下框 = 刚优化出来的；每框分正负两层，中间那条能拖。
  「↑ 顶掉上框」换上去，「→ 送进优化节点」写回 CLIP 节点。「⏻ 关机」= 旁路，节点变暗但不收起来。
· 计时器 + 桌面浮窗：到点响一声；浮窗是独立的，不跟画布缩放。浮窗在「⏱ 计时设置」里开关。
· 局部重绘 · 叠图贴片：画廊里涂两笔 → 自动裁切放大 → 重绘 → 按原坐标贴回；
  「素材模式」能把图片叠到底图上、单独擦边融合（提示词画不出来的小件就靠它）。

【工具这边】
· 模式二「★ 收藏键」：点亮后词条行前面有星，收藏的排在本小类最前；再点一下「★ 收藏键」就藏起来（数据不动）。
· 按钮图片改存本地：存进 桌面\工作流\提示词图片\ 里，ComfyUI 关着也能看到；老的网络图会自己搬过去。
· 图像模式格高统一：普通 1 格 / 横图 3 格 / 竖图 4 格；图挂了只显示占位、不会缩成一小块。
· 画师串三色 @：紫 = 普通 / 金 = 提权 / 红 = 拉黑，点一下切换。
· 世界 + 存档联动：白天 / 黑夜 / 万圣节三个世界，换世界就换它自己那份存档。
· 体验动画：下拉栏、复制↔拼装、三个模式浮现、弹窗进出都有过渡（自动的，不用设置）。

【两个修好的毛病】
· 自定义优化窗的快捷键以前拖一下节点就失灵，现在窗开着就一直有效（画布上什么都没选中时，那个键还给 ComfyUI 用）。
· 黑箱出图后右栏能正常显示缩略图了；点图片能放大（以前放大会显示成损坏的图）。

【还在、但以前没写进来的小东西】
· 「游动羽翼工具栏」上的 🧽 小字橡皮擦：按住拖到任意节点的一行灰字上松手，那一行就没了（只影响那一颗，右键能恢复）。
· 拼装模式二「🎲 随机抽卡」：每张卡右上角那颗 🔍 只在这一格里抽含某个词的；底部「⚡ 导出为按钮并同步到节点」。
· 模式二小分类行末尾那颗「＋」：可以拿一份手译表 / 自建词表当范围，建一个颜色不同的小分类。
· 顶栏「添加快捷方式」那颗红按钮：把工具放到桌面 / 从桌面删掉（要用启动器打开才管用）。
